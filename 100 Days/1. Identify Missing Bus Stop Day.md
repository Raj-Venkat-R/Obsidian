# 🚌 Identify Missing Bus Stop Day

## 📌 Problem Summary

Avinash travels through bus stops **1 to N** daily.

For each test case:
- You are given **7 days (MON → SUN)**.
- Each day contains a list of visited bus stops.

### 🎯 Goal
- Identify which days have **exactly ONE missing stop**.
- If no such day exists → print `N/A`.

---

## 🧠 Key Insight

We are NOT given `N` directly.

### 💡 Trick:
- At least one day will contain **all stops (1 → N)**.
- So:
  
```text
N = maximum size of any day's list
```

---

## 🔍 Observations

| Condition        | Meaning                  |
|----------------|------------------------|
| size == N       | No missing stop        |
| size == N - 1   | Exactly ONE missing    |

---

## ⚙️ Approach

### Step 1: Read Input
- For each test case:
  - Read 7 lines (each day)
  - Store them in a list

### Step 2: Find N
- Compute:
```text
N = max(size of all 7 days)
```

### Step 3: Identify Missing Days
- For each day:
  - If `size == N - 1`
    → print that day

### Step 4: Edge Case
- If no such day exists:
```text
print "N/A"
```

---

## 🧾 Java Implementation

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int T = sc.nextInt();
        sc.nextLine();

        String[] days = {"MON", "TUE", "WED", "THU", "FRI", "SAT", "SUN"};

        while (T-- > 0) {
            List<List<Integer>> week = new ArrayList<>();
            int maxSize = 0;

            // Read 7 days
            for (int i = 0; i < 7; i++) {
                String line = sc.nextLine().trim();
                String[] parts = line.split(" ");

                List<Integer> stops = new ArrayList<>();
                for (String p : parts) {
                    stops.add(Integer.parseInt(p));
                }

                week.add(stops);
                maxSize = Math.max(maxSize, stops.size());
            }

            boolean found = false;

            // Check for missing stop day
            for (int i = 0; i < 7; i++) {
                if (week.get(i).size() == maxSize - 1) {
                    System.out.println(days[i]);
                    found = true;
                }
            }

            if (!found) {
                System.out.println("N/A");
            }
        }
    }
}
```
