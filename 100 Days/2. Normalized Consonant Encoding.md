# Normalized Consonant Encoding

## 🧠 Problem Overview
Given a string `s` containing uppercase and lowercase English letters:

### Perform the following transformations:
1. Convert the string to **lowercase**
2. Remove all **vowels**
3. For every remaining character (**consonant**), prepend a `"."`

### Vowels:
`a, e, i, o, u, y`

---

## 📌 Example

### Input
```
tour
```

### Process
- Lowercase → `tour`
- Remove vowels → `t`, `r`
- Add "." before each → `.t.r`

### Output
```
.t.r
```

---

## 🧩 Key Concepts

### 1. Lowercase Conversion
Ensures uniform processing:
```java
s = s.toLowerCase();
```

---

### 2. Vowel Filtering
We skip characters that are vowels.

#### Option 1: Using HashSet
```java
Set<Character> vowels = Set.of('a','e','i','o','u','y');
```

#### Option 2 (Better): Direct Check
```java
if("aeiouy".indexOf(ch) != -1)
```

👉 Faster and avoids extra space.

---

### 3. StringBuilder Usage
Efficient string construction:

❌ Wrong:
```java
sb += "." + ch;
```

✔ Correct:
```java
sb.append(".").append(ch);
```

---

## ⚡ Optimal Approach

### Algorithm
1. Convert string to lowercase
2. Iterate through each character
3. If character is **not a vowel**:
   - Append `"." + ch` to result
4. Return final string

---

## 💻 Code Implementation

```java
import java.util.*;

class Main{
    public static void main(String[] args){
        Scanner sc = new Scanner(System.in);
        String s = sc.nextLine().toLowerCase();

        StringBuilder sb = new StringBuilder();

        for(char ch : s.toCharArray()){
            if("aeiouy".indexOf(ch) != -1) continue;
            sb.append(".").append(ch);
        }

        System.out.println(sb.toString());
    }
}
```

## ⚠️ Common Mistakes

1. ❌ Forgetting `.toLowerCase()`
2. ❌ Using `+=` with `StringBuilder`
3. ❌ Missing `'y'` as a vowel
4. ❌ Using unnecessary data structures

---

## 🚀 Takeaway

- Prefer **StringBuilder** for mutable strings
- Avoid unnecessary structures when simple checks work
- Always normalize input (like lowercase) before processing

---

## 🧪 Practice Variations

1. Remove only `a, e, i, o, u` (exclude `y`)
2. Replace vowels instead of removing them
3. Reverse output after processing
4. Keep vowels, remove consonants
