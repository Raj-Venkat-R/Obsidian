## Problem Summary
Given an integer `n`, return the number of **unique BSTs** that can be formed using values:

```
1 to n
```

---

## Key Idea

For each number `i` (1 to n):

```
Assume i is the root
```

Then:
- Left subtree → nodes `[1 ... i-1]`
- Right subtree → nodes `[i+1 ... n]`

---

## Recurrence Relation

```
dp[i] = sum of (dp[left] * dp[right])
```

Where:

```
dp[i] += dp[j-1] * dp[i-j]
```

- `j` = root position
- `j-1` = nodes in left subtree
- `i-j` = nodes in right subtree

---

## Base Cases

```
dp[0] = 1   (empty tree)
dp[1] = 1   (single node)
```

---

## Example

For `n = 3`:

```
dp[3] =
dp[0]*dp[2] +
dp[1]*dp[1] +
dp[2]*dp[0]

= 1*2 + 1*1 + 2*1 = 5
```

---

## Java Code (Final)

```java
class Solution {
    public int numTrees(int n) {

        long[] dp = new long[n + 1];

        dp[0] = 1;
        if(n >= 1) dp[1] = 1;

        for(int i = 2; i <= n; i++){
            for(int j = 1; j <= i; j++){
                dp[i] += dp[j - 1] * dp[i - j];
            }
        }

        return (int) dp[n];
    }
}
```

## Mathematical Insight (Catalan Number)

This problem follows:

```
C(n) = (1 / (n+1)) * (2n choose n)
```

Sequence:

```
n = 0 → 1
n = 1 → 1
n = 2 → 2
n = 3 → 5
n = 4 → 14
```

## Common Mistakes

- Forgetting dp[0] = 1
- Mixing left/right counts
- Using int (overflow risk → use long)
- Wrong loop bounds
