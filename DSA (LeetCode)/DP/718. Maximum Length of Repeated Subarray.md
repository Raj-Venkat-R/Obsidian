## Problem Summary
Given two integer arrays `nums1` and `nums2`, return the length of the **longest common subarray**.

Important:
```
Subarray = contiguous
```

---

## Key Idea

Use 2D DP:

```
dp[i][j] = length of longest common subarray
ending at nums1[i-1] and nums2[j-1]
```

---

## Transition

### If elements match:

```
nums1[i-1] == nums2[j-1]

dp[i][j] = dp[i-1][j-1] + 1
```

---

### If not match:

```
dp[i][j] = 0
```

Why?
```
Subarray must be continuous → break on mismatch
```

---

## Base Case

```
dp[0][*] = 0
dp[*][0] = 0
```

---

## Final Answer

```
max value in dp table
```

(You correctly track it using `max`)

---

## Example

```
nums1 = [1,2,3,2,1]
nums2 = [3,2,1,4,7]
```

Common subarray:
```
[3,2,1] → length = 3
```

---

## Java Code (Final)

```java
class Solution {
    public int findLength(int[] nums1, int[] nums2) {

        int[][] dp = new int[nums1.length + 1][nums2.length + 1];
        int max = 0;

        for(int i = 1; i <= nums1.length; i++){
            for(int j = 1; j <= nums2.length; j++){

                if(nums1[i - 1] == nums2[j - 1]){
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                    max = Math.max(max, dp[i][j]);
                } else {
                    dp[i][j] = 0;
                }
            }
        }

        return max;
    }
}
```

## Patterns Learned

- DP for contiguous matching
- Diagonal dependency
- Reset on mismatch

---

## Common Mistakes

- Using LCS logic (max of left/top) ❌
- Forgetting to reset to 0
- Not tracking global max

---

## Key Insight

```
Match → extend diagonal
Mismatch → reset to 0
```

---

## LCS vs Subarray (VERY IMPORTANT)

| Feature | LCS | Subarray |
|--------|-----|----------|
| Continuity | Not required | Required |
| On mismatch | take max | reset to 0 |
| Answer | dp[n][m] | max(dp) |
