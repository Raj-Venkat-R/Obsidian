## Problem Summary
Given two strings `text1` and `text2`, return the length of their **Longest Common Subsequence (LCS)**.

A subsequence:
```
Can skip characters but must maintain order
```

---

## Key Idea

Use **2D DP**:

```
dp[i][j] = LCS length between:
text1[0...i-1] and text2[0...j-1]
```

---

## Transition

### If characters match:

```
text1[i-1] == text2[j-1]

dp[i][j] = dp[i-1][j-1] + 1
```

---

### If characters don’t match:

```
dp[i][j] = max(dp[i-1][j], dp[i][j-1])
```

---

## Base Case

```
dp[0][*] = 0
dp[*][0] = 0
```

Meaning:
```
Empty string → no common subsequence
```

---

## Final Answer

```
dp[n][m]
```

Where:
```
n = text1.length()
m = text2.length()
```

---

## Example

```
text1 = "abcde"
text2 = "ace"
```

LCS:
```
"ace" → length = 3
```

---

## Your Code (Corrected Insight)

Your code is correct, but:

```java
return max;
```

👉 This works, but better practice is:

```java
return dp[text1.length()][text2.length()];
```

Because:

```
dp[n][m] always stores final answer
```

---

## Java Code (Final)

```java
class Solution {
    public int longestCommonSubsequence(String text1, String text2) {

        int n = text1.length();
        int m = text2.length();

        int[][] dp = new int[n + 1][m + 1];

        for(int i = 1; i <= n; i++){
            for(int j = 1; j <= m; j++){

                if(text1.charAt(i - 1) == text2.charAt(j - 1)){
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                } else {
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }

        return dp[n][m];
    }
}
```

Time Complexity:


## Key Insight

```
If match → diagonal + 1
Else → take best of left or top
```
