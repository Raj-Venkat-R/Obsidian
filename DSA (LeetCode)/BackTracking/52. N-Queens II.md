## 🔹 Problem Summary
Given an integer `n`, return the **number of distinct solutions** to the N-Queens problem.

- Place `n` queens on an `n × n` board
- No two queens attack each other
- Unlike LC 51, we only need the **count**, not the board configurations

---

## 🔹 My First Thought (Initial Approach)
Reuse the N-Queens backtracking logic from LC 51.

Instead of storing board configurations:
- Just count valid arrangements.

---

## 🔹 Key Observation
- Place queens **row by row**
- Only need to track:
  - Columns
  - Main diagonals
  - Anti-diagonals
- Use boolean arrays for O(1) conflict checking
- When `row == n`, one valid solution is found → increment counter

Diagonal indexing:
- Main diagonal → `row - col + n`
- Anti-diagonal → `row + col`

---

## 🔹 Final Approach (Step-by-Step in English)

1. Initialize:
   - A board filled with `'.'`
   - Boolean arrays for columns and diagonals
   - A class-level counter `result`
2. Start backtracking from row `0`.
3. For each column in the current row:
   - If column or diagonals are occupied → skip.
   - Otherwise:
     - Place the queen.
     - Mark column and diagonals.
     - Recurse to next row.
4. If `row == n`:
   - Increment `result`
   - Return.
5. After recursion:
   - Remove queen.
   - Unmark column and diagonals.
6. Return `result` after traversal.

## 🔹 Java Code (Final)
> ⚠️ Code added after fully understanding the logic.

```java
class Solution {
    int result = 0;

    public int totalNQueens(int n) {
        result = 0;

        char[][] board = new char[n][n];
        for (int i = 0; i < n; i++) {
            Arrays.fill(board[i], '.');
        }

        boolean[] columns = new boolean[n];
        boolean[] diag1 = new boolean[2 * n];
        boolean[] diag2 = new boolean[2 * n];

        backtrack(0, board, columns, diag1, diag2, n);
        return result;
    }

    private void backtrack(int row, char[][] board,
                           boolean[] columns,
                           boolean[] diag1,
                           boolean[] diag2,
                           int n) {

        if (row == n) {
            result++;
            return;
        }

        for (int col = 0; col < n; col++) {
            int d1 = row - col + n;
            int d2 = row + col;

            if (columns[col] || diag1[d1] || diag2[d2]) continue;

            board[row][col] = 'Q';
            columns[col] = true;
            diag1[d1] = true;
            diag2[d2] = true;

            backtrack(row + 1, board, columns, diag1, diag2, n);

            board[row][col] = '.';
            columns[col] = false;
            diag1[d1] = false;
            diag2[d2] = false;
        }
    }
}
```

## 🔹 Time & Space Complexity

Time Complexity:
- Approximately O(n!) in worst case

Space Complexity:
- O(n) recursion depth
- O(n²) for board
- O(n) for helper arrays

---

## 🔹 Patterns Learned

- Backtracking with counting instead of storing results
- Use class variable for shared counter
- Diagonal indexing trick
- Place → Recurse → Undo pattern
- Pruning invalid states early improves efficiency

---

## 🔹 Common Mistakes to Avoid

- Passing primitive counter in recursion (pass-by-value issue)
- Forgetting to `return` when `row == n`
- Incorrect diagonal indexing
- Not undoing state during backtracking
