## 🔹 Problem Summary
Place `n` queens on an `n × n` chessboard such that:

- No two queens attack each other.
- Queens cannot share:
  - the same column
  - the same diagonal
  - the same row

Return all possible valid board configurations.

---

## 🔹 My First Thought (Initial Approach)
- Try placing queens randomly and check validity afterward.

❌ Checking the entire board repeatedly is inefficient.

---

## 🔹 Key Observation
- We place queens **row by row**.
- Since we place one queen per row, row conflicts are automatically avoided.
- We only need to track:
  - Columns
  - Main diagonals
  - Anti-diagonals

Diagonal math:
- Main diagonal → `row - col`
- Anti-diagonal → `row + col`
- To avoid negative indices: use `row - col + n`

We use boolean arrays to mark occupied positions for O(1) checks.

---

## 🔹 Final Approach (Step-by-Step in English)

1. Initialize an empty board filled with `'.'`.
2. Maintain three boolean arrays:
   - `columns[col]`
   - `diag1[row - col + n]`
   - `diag2[row + col]`
3. Start backtracking from row `0`.
4. For each column in the current row:
   - If the column or diagonals are occupied, skip.
   - Otherwise:
     - Place the queen.
     - Mark column and diagonals as occupied.
     - Recursively move to the next row.
5. If `row == n`, a valid configuration is found:
   - Convert the board to a list of strings.
   - Add to result.
6. Backtrack:
   - Remove the queen.
   - Unmark column and diagonals.

## 🔹 Java Code (Final)
> ⚠️ Code added after fully understandings the logic.

```java
class Solution {
    public List<List<String>> solveNQueens(int n) {
        List<List<String>> result = new ArrayList<>();
        char[][] board = new char[n][n];

        for (int i = 0; i < n; i++) {
            Arrays.fill(board[i], '.');
        }

        boolean[] columns = new boolean[n];
        boolean[] diag1 = new boolean[2 * n];
        boolean[] diag2 = new boolean[2 * n];

        backtrack(0, result, board, columns, diag1, diag2, n);
        return result;
    }

    private void backtrack(int row, List<List<String>> result,
                           char[][] board, boolean[] columns,
                           boolean[] diag1, boolean[] diag2, int n) {

        if (row == n) {
            result.add(construct(board));
            return;
        }

        for (int col = 0; col < n; col++) {
            int d1 = row - col + n;
            int d2 = row + col;

            if (columns[col] || diag1[d1] || diag2[d2]) continue;

            board[row][col] = 'Q';
            columns[col] = true;
            diag1[d1] = true;
            diag2[d2] = true;

            backtrack(row + 1, result, board, columns, diag1, diag2, n);

            board[row][col] = '.';
            columns[col] = false;
            diag1[d1] = false;
            diag2[d2] = false;
        }
    }

    private List<String> construct(char[][] board) {
        List<String> list = new ArrayList<>();
        for (char[] row : board) {
            list.add(new String(row));
        }
        return list;
    }
}
```

## 🔹 Time & Space Complexity

Time Complexity:
- Approximately O(n!) in the worst case

Space Complexity:
- O(n) recursion depth
- O(n²) for board storage

---

## 🔹 Patterns Learned

- Classic Backtracking template
- Place → Recurse → Undo
- Use boolean arrays for O(1) validity checks
- Row-wise placement simplifies constraints
- Diagonal indexing trick (`row - col + n`, `row + col`)

---

## 🔹 Common Mistakes to Avoid

- Forgetting to `return` after adding solution
- Not undoing changes during backtracking
- Incorrect diagonal indexing
- Checking entire board instead of using helper arrays
- Using slow validity checks inside recursion
