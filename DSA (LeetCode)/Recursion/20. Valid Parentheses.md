## Problem Summary
Given a string `s` containing:
- `'(' , ')' , '{' , '}' , '[' , ']'`

Return `true` if:
- Every opening bracket has a corresponding closing bracket
- Brackets are closed in the correct order

---

## My First Thought (Initial Approach)
- Traverse the string
- Match opening and closing brackets

But direct matching is tricky because order matters.

---

## Key Observation
- Use a **stack** to track opening brackets
- The most recent opening bracket must match the current closing bracket

This follows **LIFO (Last In First Out)**

---

## Final Approach (Step-by-Step in English)

1. Initialize an empty stack
2. Traverse each character:
   - If it is an opening bracket:
     - Push into stack
   - Else (closing bracket):
     - If stack is empty → invalid
     - Check if top matches:
       - If not → invalid
       - Else → pop
3. After traversal:
   - If stack is empty → valid
   - Else → invalid

---

## Example Walkthrough

Input:

```
s = "()[]{}"
```

Process:

```
( → push
) → pop

[ → push
] → pop

{ → push
} → pop
```

Stack becomes empty → valid

---

## Java Code (Final)

```java
class Solution {
    public boolean isValid(String s) {
        Stack<Character> stack = new Stack<>();

        int i = 0;
        while(i < s.length()){
            char ch = s.charAt(i);

            if(ch == '[' || ch ==  '{' || ch == '('){
                stack.push(ch);
            } else {
                if(stack.isEmpty()) return false;
                else if(ch == ']' && stack.peek() != '[') return false;
                else if(ch == '}' && stack.peek() != '{') return false;
                else if(ch == ')' && stack.peek() != '(') return false;
                else stack.pop();
            }

            i++;
        }

        return stack.isEmpty();
    }
}
```

## Common Mistakes to Avoid

- Not checking if stack is empty before peek
- Forgetting to pop after successful match
- Not handling all bracket types
- Returning true without checking stack emptiness
