## Problem Summary
You are given a 2D grid where:
- `0` → empty cell
- `1` → fresh orange
- `2` → rotten orange

Every minute:
- Rotten oranges spread to adjacent fresh oranges (4 directions)

Return the **minimum time required** to rot all oranges.  
If impossible, return `-1`.

---

## My First Thought (Initial Approach)
- Start from rotten oranges.
- Spread rot to adjacent fresh oranges.
- Count time taken.

---

## Key Observation
- This is a **Multi-Source BFS problem**.
- All rotten oranges act as **starting points simultaneously**.
- Each BFS level represents **1 minute**.

---

## Final Approach (Step-by-Step in English)

1. Traverse the grid:
   - Add all rotten oranges (`2`) into queue
   - Count number of fresh oranges

2. Initialize `count = 0` (time)

3. Perform BFS:
   - While queue is not empty and fresh > 0:
     - Process current level (queue size)
     - For each cell:
       - Explore 4 directions
       - If neighbor is fresh:
         - Convert to rotten
         - Decrement fresh count
         - Add to queue
     - Increment time

4. After BFS:
   - If fresh == 0 → return time
   - Else → return -1

---

## Direction Array

```
{0,1}   → right
{1,0}   → down
{0,-1}  → left
{-1,0}  → up
```

## Java Code (Corrected)

```java
class Solution {
    public int orangesRotting(int[][] grid) {
        int fresh = 0;
        Queue<int[]> q = new ArrayDeque<>();

        for(int i = 0; i < grid.length; i++){
            for(int j = 0; j < grid[0].length; j++){
                if(grid[i][j] == 2) q.offer(new int[]{i , j});
                if(grid[i][j] == 1) fresh++;
            }
        }

        int time = 0;
        int[][] dir = {{0,1},{1,0},{0,-1},{-1,0}};

        while(!q.isEmpty() && fresh > 0){
            int size = q.size();
            time++;

            for(int i = 0; i < size; i++){
                int[] arr = q.poll();
                int r = arr[0], c = arr[1];

                for(int[] d : dir){
                    int nr = r + d[0];
                    int nc = c + d[1];

                    if(nr >= 0 && nc >= 0 &&
                       nr < grid.length && nc < grid[0].length &&
                       grid[nr][nc] == 1){

                        grid[nr][nc] = 2;
                        fresh--;
                        q.offer(new int[]{nr, nc});
                    }
                }
            }
        }

        return fresh == 0 ? time : -1;
    }
}
```

## Patterns Learned

- Multi-source BFS
- Level-order traversal in grid

- BFS layer = time unit

## Common Mistakes to Avoid

- Using `while` instead of `if` for neighbor check
- Not processing level by level (missing time logic)
- Forgetting to decrement fresh count
- Not checking boundaries properly
- Syntax errors like `fresh > 0#`
