## Problem Summary
You are given a 2D grid of `0`s and `1`s where:
- `1` → land
- `0` → water

An island is formed by connecting adjacent lands (up, down, left, right).

Return the **maximum area of an island**.

---

## My First Thought (Initial Approach)
- Traverse the grid.
- When a `1` is found, explore all connected `1`s.
- Count the size of that island.
- Track the maximum size.

---

## Key Observation
- This is a **graph problem on a grid**.
- Each cell is a node.
- Connections exist in 4 directions.
- Use **DFS (Stack)** or BFS to explore the island.
- Mark visited cells to avoid revisiting.

---

## Final Approach (Step-by-Step in English)

1. Traverse every cell in the grid.
2. If a cell contains `1`:
   - Start DFS using a stack.
   - Mark the cell as visited (`0`).
   - Initialize `count = 0`.
3. While stack is not empty:
   - Pop a cell.
   - Increment `count`.
   - Explore all 4 directions:
     - If neighbor is valid and equals `1`:
       - Mark it as visited
       - Push into stack
4. After DFS ends:
   - Update `max = max(max, count)`
5. Continue for all cells.
6. Return `max`.

---

## Direction Array

Used for movement in 4 directions:

```
{0,1}   → right
{1,0}   → down
{0,-1}  → left
{-1,0}  → up
```

## Example Walkthrough

Input:

```
grid = [
 [0,0,1,0],
 [1,1,1,0],
 [0,1,0,0]
]
```

Process:
- Start DFS at first `1`
- Explore all connected land
- Count area

Final Output:
```

```

## Java Code (Final)

```java
class Solution {
    public int maxAreaOfIsland(int[][] grid) {
        int[][] dir = {{0,1},{1,0},{0,-1},{-1,0}};
        int max = 0;

        Stack<int[]> s = new Stack<>();

        for(int i = 0; i < grid.length; i++){
            for(int j = 0; j < grid[0].length; j++){

                if(grid[i][j] == 1){
                    s.push(new int[]{i , j});
                    grid[i][j] = 0;

                    int count = 0;

                    while(!s.isEmpty()){
                        count++;

                        int[] arr = s.pop();
                        int r = arr[0], c = arr[1];

                        for(int[] d: dir){
                            int nr = r + d[0];
                            int nc = c + d[1];

                            if(nr >= 0 && nc >= 0 &&
                               nr < grid.length && nc < grid[0].length &&
                               grid[nr][nc] == 1){

                                grid[nr][nc] = 0;
                                s.push(new int[]{nr, nc});
                            }
                        }
                    }

                    max = Math.max(max, count);
                }
            }
        }

        return max;
    }
}
```

## Patterns Learned

- DFS on grid
- Using stack for traversal
- Flood fill technique
- Marking visited by modifying input
- Direction array usage

---

## Common Mistakes to Avoid

- Not marking visited cells (causes infinite loop)
- Forgetting boundary checks
- Mixing up row and column indices
- Using recursion without handling stack overflow
