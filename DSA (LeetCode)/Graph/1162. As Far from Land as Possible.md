## Problem Summary
You are given an `n x n` grid where:
- `1` → land
- `0` → water

Return the distance of the water cell that is **farthest from any land**.

Distance is measured in 4 directions.

If no water or no land exists, return `-1`.

---

## My First Thought (Initial Approach)
- For each water cell, run BFS to find nearest land.

This is inefficient:
- O(n³)

---

## Key Observation
- Instead of starting from water, start from all land cells.
- This is a **multi-source BFS problem**.
- BFS expansion naturally gives the **minimum distance**.

---

## Final Approach (Step-by-Step in English)

1. Traverse grid:
   - Add all land cells (`1`) into queue

2. Edge cases:
   - If no land OR all land → return `-1`

3. Perform BFS:
   - Expand from all land simultaneously
   - For each neighbor:
     - If it is water (`0`):
       - Update distance
       - Push into queue

4. Track the maximum distance during BFS

5. Return the maximum distance

---

Input:

```
grid = [
 [1,0,1],
```

- Spread outward layer by layer

## Java Code (Final)

```java
class Solution {
    public int maxDistance(int[][] grid) {
        int r = grid.length;
        int c = grid[0].length;

        Queue<int[]> q = new ArrayDeque<>();

        for(int i = 0; i < r; i++){
            for(int j = 0; j < c; j++){
                if(grid[i][j] == 1){
                    q.offer(new int[]{i, j});
                }
            }
        }

        if(q.isEmpty() || q.size() == r * c) return -1;

        int[][] dir = {{0,1},{1,0},{0,-1},{-1,0}};
        int max = 0;

        while(!q.isEmpty()){
            int[] arr = q.poll();
            int row = arr[0], col = arr[1];

            for(int[] d : dir){
                int nr = row + d[0];
                int nc = col + d[1];

                if(nr >= 0 && nc >= 0 &&
                   nr < r && nc < c &&
                   grid[nr][nc] == 0){

                    grid[nr][nc] = grid[row][col] + 1;
                    max = Math.max(max, grid[nr][nc]);

                    q.offer(new int[]{nr, nc});
                }
            }
        }

        return max - 1;
    }
}
```

## Common Mistakes to Avoid

- Using `while(!q.isEmpty() || condition)` instead of `&&` or proper check
- Forgetting edge cases (all land / all water)
- Incorrect index updates (`col` vs `row`)
- Using wrong initial values
- Adding `+1` or `-1` incorrectly in return
