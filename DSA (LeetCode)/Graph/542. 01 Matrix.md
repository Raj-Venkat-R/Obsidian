## Problem Summary
You are given a binary matrix `mat` consisting of `0`s and `1`s.

Return a matrix where each cell contains the **distance to the nearest 0**.

Distance is measured in 4 directions (up, down, left, right).

---

## My First Thought (Initial Approach)
- For each cell with `1`, find the nearest `0` using BFS/DFS.

This works but is inefficient:
- O((m × n)²)

---

## Key Observation
- Instead of starting from `1`s, start from all `0`s simultaneously.
- This is a **multi-source BFS problem**.
- All `0`s act as starting points.

---

## Final Approach (Step-by-Step in English)

1. Traverse the grid:
   - Add all `0` cells to queue
   - Mark all `1`s as `-1` (unvisited)

2. Perform BFS:
   - For each cell in queue:
     - Explore 4 directions
     - If neighbor is `-1`:
       - Update distance = current + 1
       - Add to queue

3. Continue until queue is empty

4. Return updated matrix

---

## Example Walkthrough

Input:

```
mat = [
 [0,0,0],
 [0,1,0],
 [1,1,1]
]
```

Process:
- Start from all 0s
- Spread distances outward

Final Output:

```
[
 [0,0,0],
 [0,1,0],
 [1,2,1]
]
```

## Java Code (Corrected)

```java
class Solution {
    public int[][] updateMatrix(int[][] mat) {
        int r = mat.length;
        int c = mat[0].length;

        Queue<int[]> q = new ArrayDeque<>();

        for(int i = 0; i < r; i++){
            for(int j = 0; j < c; j++){
                if(mat[i][j] == 0) q.offer(new int[]{i, j});
                else mat[i][j] = -1;
            }
        }

        int[][] dir = {{0,1},{1,0},{0,-1},{-1,0}};

        while(!q.isEmpty()){
            int[] arr = q.poll();
            int row = arr[0], col = arr[1];

            for(int[] d: dir){
                int nr = row + d[0];
                int nc = col + d[1];

                if(nr >= 0 && nc >= 0 &&
                   nr < r && nc < c &&
                   mat[nr][nc] == -1){

                    mat[nr][nc] = mat[row][col] + 1;
                    q.offer(new int[]{nr, nc});
                }
            }
        }

        return mat;
    }
}
```

## Common Mistakes to Avoid

- Using BFS separately for each cell
- Using `while` instead of `if` for neighbor condition
- Not marking visited cells
- Forgetting boundary checks
- Not initializing `1`s properly
