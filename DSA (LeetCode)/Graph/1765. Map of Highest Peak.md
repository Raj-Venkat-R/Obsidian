## Problem Summary
You are given a binary matrix `isWater` where:
- `1` → water
- `0` → land

You need to assign heights such that:
- Water cells have height `0`
- Adjacent cells differ by at most `1`
- Heights are minimized

Return the height matrix.

---

## My First Thought (Initial Approach)
- Start from each land cell and find distance to nearest water.

This is inefficient because it repeats BFS multiple times.

---

## Key Observation
- Water cells (`1`) are the **sources**.
- Heights increase as we move away from water.
- This is a **multi-source BFS problem**.

---

## Final Approach (Step-by-Step in English)

1. Traverse the grid:
   - If cell is water (`1`):
     - Set height = `0`
     - Add to queue
   - If land (`0`):
     - Mark as `-1` (unvisited)

2. Perform BFS:
   - For each cell:
     - Explore 4 directions
     - If neighbor is `-1`:
       - Assign height = current + 1
       - Add to queue

3. Continue until all cells are processed

4. Return the updated grid

## Java Code (Final)

```java
class Solution {
    public int[][] highestPeak(int[][] isWater) {
        int row = isWater.length;
        int col = isWater[0].length;

        Queue<int[]> q = new ArrayDeque<>();

        for(int i = 0; i < row; i++){
            for(int j = 0; j < col; j++){
                if(isWater[i][j] == 1){
                    isWater[i][j] = 0;
                    q.offer(new int[]{i , j});
                } else {
                    isWater[i][j] = -1;
                }
            }
        }

        int[][] dir = {{0,1},{1,0},{0,-1},{-1,0}};

        while(!q.isEmpty()){
            int[] arr = q.poll();
            int r = arr[0], c = arr[1];

            for(int[] d: dir){
                int nr = r + d[0];
                int nc = c + d[1];

                if(nr >= 0 && nc >= 0 &&
                   nr < row && nc < col &&
                   isWater[nr][nc] == -1){

                    isWater[nr][nc] = isWater[r][c] + 1;
                    q.offer(new int[]{nr, nc});
                }
            }
        }

        return isWater;
    }
}
```

## Patterns Learned

- Multi-source BFS
- Distance propagation
- Reusing input grid as visited + result
- Level-by-level expansion

---

## Common Mistakes to Avoid

- Starting BFS from land instead of water
- Not marking unvisited cells (`-1`)
- Forgetting boundary checks
- Using DFS instead of BFS (won’t guarantee minimum height)
