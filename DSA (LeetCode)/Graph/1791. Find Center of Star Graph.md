## Problem Summary
You are given a graph represented by `edges`.

The graph forms a **star graph**, meaning:
- One central node connects to all other nodes
- All edges include the center node

Return the **center of the star graph**.

---

## My First Thought (Initial Approach)
- Count the degree (frequency) of each node
- The node with highest degree is the center

This works but requires extra space.

---

## Key Observation
- In a star graph, the **center node appears in every edge**
- So, it must be present in the **first two edges**

Thus:
- Compare the first two edges
- The common node is the answer

---

## Final Approach (Step-by-Step in English)

1. Look at the first two edges:
   - edges[0] = [a, b]
   - edges[1] = [c, d]

2. Check:
   - If `b == c` or `b == d` → return `b`
   - Otherwise → return `a`

3. No need to process the entire array

---

## Example Walkthrough

Input:

```
edges = [[1,2],[2,3],[4,2]]
```

Process:

```
edges[0] = [1,2]
edges[1] = [2,3]

Common node = 2
```

Final Output:
```
2
```

---

## Java Code (Final)

```java
class Solution {
    public int findCenter(int[][] edges) {
        if(edges[0][1] == edges[1][0] || edges[0][1] == edges[1][1]) {
            return edges[0][1];
        } else {
            return edges[0][0];
        }
    }
}
```
