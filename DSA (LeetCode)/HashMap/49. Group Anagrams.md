## Problem Summary
Given an array of strings `strs`, group the anagrams together.

Two strings are anagrams if they contain the **same characters with same frequency**.

---

## Key Idea
Instead of comparing every pair of strings:

```
Convert each string into a unique key based on character frequency
```

All anagrams will generate the **same key**.

---

## Why Frequency Instead of Sorting

Sorting approach:
```
"eat" → "aet"
```

Frequency approach:
```
"eat" → [1,0,0,...,1,...,1]
```

Convert to string:
```
"1#0#0#...#1#...#1"
```

---

## Final Approach (Step-by-Step in English)

1. Create a HashMap:
   ```
   key → list of anagrams
   ```

2. For each string:
   - Create `freq[26]`
   - Count each character
   - Build a string key using `#` separator

3. Insert into map:
   - If key exists → add to list
   - Else → create new list

4. Return all values of the map

---

## Example

Input:

```
["eat","tea","tan","ate","nat","bat"]
```

Map:

```
"aet" or freq-key → ["eat","tea","ate"]
"ant" → ["tan","nat"]
"abt" → ["bat"]
```

Output:

```
[["eat","tea","ate"],["tan","nat"],["bat"]]
```

---

## Java Code (Final)

```java
class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        Map<String, List<String>> map = new HashMap<>();

        for(String str : strs){

            int[] freq = new int[26];

            for(char ch : str.toCharArray()){
                freq[ch - 'a']++;
            }

            StringBuilder sb = new StringBuilder();
            for(int f : freq){
                sb.append(f).append("#");
            }

            String key = sb.toString();

            map.putIfAbsent(key, new ArrayList<>());
            map.get(key).add(str);
        }

        return new ArrayList<>(map.values());
    }
}
```

## Time & Space Complexity

Time Complexity:
- O(n * k)
  - n = number of strings
  - k = length of each string

Space Complexity:
- O(n * k)

---

## Patterns Learned

- HashMap grouping
- Frequency array encoding
- String key construction
- Avoiding pairwise comparison

---

## Common Mistakes to Avoid

- Using `int[]` directly as key
- Forgetting separator (`#`) → causes collisions
- Using `set` instead of `map`
- Calling `toString()` multiple times unnecessarily
- Using `add()` inside `put()` (wrong return type)

---

## Alternative Approach

Sorting-based key:

```
Sort string → use as key
```

Time:
- O(n * k log k)

---

## Key Insight

```
Same frequency → same key → same group
```
