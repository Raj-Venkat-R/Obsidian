## Problem Summary
Determine if a 9×9 Sudoku board is valid.

Rules:
- Each row must have unique digits (1–9)
- Each column must have unique digits
- Each 3×3 sub-box must have unique digits

Empty cells are represented by `.`

---

## Key Idea
Instead of checking rows, columns, and boxes separately:

```
Encode constraints into strings and store in a single HashSet
```

---

## Final Approach (Step-by-Step in English)

1. Create a HashSet to store seen constraints

2. Traverse each cell `(i, j)`:
   - Skip if `'.'`

3. For each value `val`, generate 3 keys:
   ```
   val-row-i
   val-col-j
   val-box-(i/3)-(j/3)
   ```

4. If any key already exists → invalid

5. Otherwise, add all 3 keys to the set

6. If no conflicts → return true

---

## Example

For value `'5'` at `(1,2)`:

```
"5-row-1"
"5-col-2"
"5-box-0-0"
```

If any repeats → invalid Sudoku

---

## Java Code (Final)

```java
class Solution {
    public boolean isValidSudoku(char[][] board) {
        Set<String> set = new HashSet<>();

        for(int i = 0; i < board.length; i++){
            for(int j = 0; j < board[0].length; j++){

                char val = board[i][j];
                if(val == '.') continue;

                String row = val + "-row-" + i;
                String col = val + "-col-" + j;
                String box = val + "-box-" + i/3 + "-" + j/3;

                if(set.contains(row) || set.contains(col) || set.contains(box)){
                    return false;
                }

                set.add(row);
                set.add(col);
                set.add(box);
            }
        }

        return true;
    }
}
```

## Patterns Learned

- Constraint encoding using strings
- HashSet for duplicate detection
- Grid traversal
- Using `(i/3, j/3)` for sub-box indexing

---

## Common Mistakes to Avoid

- Not skipping `'.'`
- Incorrect box calculation
- Using separate maps unnecessarily
- Missing one constraint (row/col/box)
