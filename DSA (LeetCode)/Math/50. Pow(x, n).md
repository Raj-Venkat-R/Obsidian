## Problem Summary
Implement `pow(x, n)` which calculates `x` raised to the power `n`.

---

## My First Thought (Initial Approach)
- Multiply `x` repeatedly `n` times

Problems:
- Time Complexity = O(n)
- Fails for large `n` (TLE)
- Issues with negative powers and overflow

---

## Key Observation
Instead of multiplying one by one:

```
x^n = (x^(n/2)) * (x^(n/2))
```

If `n` is odd:

```
x^n = x * x^(n-1)
```

This reduces complexity to:

```
O(log n)
```

---

## Final Approach (Step-by-Step in English)

1. Convert `n` to long (to handle overflow)
2. If `n < 0`:
   - Convert to positive
   - Invert result later (`1 / result`)
3. Use binary exponentiation:
   - If `n` is even:
     - `x = x * x`
     - `n = n / 2`
   - If `n` is odd:
     - Multiply result with `x`
     - Decrease `n`
4. Repeat until `n == 0`

---

## Example Walkthrough

Input:

```
x = 2, n = 10
```

Process:

```
2^10 = (2^5)^2
2^5 = 2 * (2^4)
2^4 = (2^2)^2
2^2 = (2^1)^2
```

Final Output:
```
1024
```

---

## Java Code (Optimal)

```java
class Solution {
    public double myPow(double x, int n) {
        long N = n;
        
        if(N < 0){
            x = 1 / x;
            N = -N;
        }

        double res = 1;

        while(N > 0){
            if((N % 2) == 1){
                res *= x;
            }
            x *= x;
            N /= 2;
        }

        return res;
    }
}
```

## Common Mistakes to Avoid

- Using linear multiplication (O(n))
- Not converting `n` to long (overflow for `Integer.MIN_VALUE`)
- Incorrect handling of negative powers
- Writing unnecessary edge cases (like x == -1 checks)
