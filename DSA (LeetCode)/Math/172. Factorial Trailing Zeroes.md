## Problem Summary
Given an integer `n`, return the number of trailing zeroes in `n!` (n factorial).

Trailing zeroes are the number of zeros at the end of the factorial result.

---

## My First Thought (Initial Approach)
- Compute `n!` and count how many zeros are at the end.

This approach is not feasible because:
- Factorial grows very large
- Causes overflow
- Inefficient for large `n`

---

## Key Observation
Trailing zeros are formed by factors of **10**.

```
10 = 2 × 5
```

In factorial:
- There are plenty of factors of 2
- The limiting factor is **5**

So, we only need to count how many times **5 appears as a factor**.

---

## Important Insight
We count:

```
n / 5       → numbers divisible by 5
n / 25      → numbers divisible by 25 (extra 5)
n / 125     → numbers divisible by 125 (extra 5)
...
```

---

## Final Approach (Step-by-Step in English)

1. Initialize `count = 0`.
2. While `n > 0`:
   - Divide `n` by 5
   - Add result to count
3. Repeat until `n` becomes 0.
4. Return `count`.

---

## Example Walkthrough

Input:
n = 25

Process:

```
25 / 5  = 5
25 / 25 = 1
```

Total:

```
5 + 1 = 6
```

Final Output:
6

---

## Java Code (Final)

```java
class Solution {
    public int trailingZeroes(int n) {
        int count = 0;

        while (n > 0) {
            n = n / 5;
            count += n;
        }

        return count;
    }
}
```

## Time & Space Complexity

Time Complexity:
- O(log₅ n)

Space Complexity:
- O(1)

## Patterns Learned

- Mathematical optimization instead of brute force
- Counting factors instead of computing factorial
- Repeated division technique

---

## Common Mistakes to Avoid

- Trying to compute factorial directly
- Counting only `n / 5` and ignoring higher powers
- Forgetting that 25, 125, etc. contribute extra factors
- Confusing factors of 2 and 5
