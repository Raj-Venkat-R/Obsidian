## Problem Summary

You are given two non-empty linked lists representing two non-negative integers.

- Digits are stored in **reverse order**.
- Each node contains **one digit**.

Return the sum as a linked list in the same reverse order.

---

## Key Idea

Simulate the addition exactly like elementary school addition.

For every pair of digits:

```
sum = digit1 + digit2 + carry
```

Store:

```
sum % 10
```

Carry forward:

```
sum / 10
```

---

## Final Approach (Step-by-Step in English)

1. Create a dummy node to build the answer.

2. Maintain a pointer:
   ```
   curr
   ```

3. Initialize:
   ```
   carry = 0
   ```

4. Traverse while:
   ```
   l1 != null
   OR
   l2 != null
   OR
   carry != 0
   ```

5. Get current values:
   ```
   val1 = l1 != null ? l1.val : 0
   val2 = l2 != null ? l2.val : 0
   ```

6. Calculate:
   ```
   sum = val1 + val2 + carry
   ```

7. Create new node:
   ```
   sum % 10
   ```

8. Update carry:
   ```
   carry = sum / 10
   ```

9. Move pointers.

10. Return:
   ```
   dummy.next
   ```

---

## Example

Input:

```
l1 = 2 → 4 → 3
l2 = 5 → 6 → 4
```

Represents:

```
342 + 465
```

Steps:

```
2 + 5 = 7

4 + 6 = 10
digit = 0
carry = 1

3 + 4 + 1 = 8
```

Output:

```
7 → 0 → 8
```

Represents:

```
807
```

## Java Code (Final)

```java
class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {

        int carry = 0;

        ListNode dummy = new ListNode(0);
        ListNode curr = dummy;

        while(l1 != null || l2 != null || carry != 0){

            int val1 = (l1 != null) ? l1.val : 0;
            int val2 = (l2 != null) ? l2.val : 0;

            int sum = val1 + val2 + carry;

            curr.next = new ListNode(sum % 10);

            carry = sum / 10;

            curr = curr.next;

            if(l1 != null) l1 = l1.next;
            if(l2 != null) l2 = l2.next;
        }

        return dummy.next;
    }
}
```

Time Complexity:

O(max(n, m))

## Common Mistakes to Avoid

- Forgetting:
  ```
  carry != 0
  ```
  in the while loop.

- Not handling different length lists.

- Returning:
  ```
  dummy
  ```
  instead of:
  ```
  dummy.next
  ```

- Forgetting:
  ```
  carry = sum / 10
  ```

---

## Key Insight

```
Treat missing nodes as value 0
and continue until both lists
and carry are exhausted.
```
