## Problem Summary

Given the head of a linked list and an integer `x`, partition the list such that:

- All nodes with value **less than x** come before
- All nodes with value **greater than or equal to x**

The **relative order** of nodes in each partition must remain the same.

---

## Key Idea

Instead of rearranging nodes in-place:

```
Create two separate linked lists:
1. Small list (< x)
2. Large list (>= x)
```

Finally, connect both lists.

---

## Final Approach (Step-by-Step in English)

1. Create two dummy nodes:
   ```
   small
   large
   ```

2. Create two pointers:
   ```
   s → tail of small list
   l → tail of large list
   ```

3. Traverse original list:
   - If node value < x:
     ```
     attach to small list
     ```
   - Else:
     ```
     attach to large list
     ```

4. Finish large list:
   ```
   l.next = null
   ```

5. Connect:
   ```
   s.next = large.next
   ```

6. Return:
   ```
   small.next
   ```

---

## Example

Input:

```
1 → 4 → 3 → 2 → 5 → 2
x = 3
```

Small list:

```
1 → 2 → 2
```

Large list:

```
4 → 3 → 5
```

Connect:

```
1 → 2 → 2 → 4 → 3 → 5
```

---

## Java Code (Final)

```java
class Solution {
    public ListNode partition(ListNode head, int x) {

        ListNode small = new ListNode(0);
        ListNode large = new ListNode(0);

        ListNode s = small;
        ListNode l = large;

        while(head != null){

            if(head.val < x){
                s.next = head;
                s = s.next;
            } else {
                l.next = head;
                l = l.next;
            }

            head = head.next;
        }

        l.next = null;
        s.next = large.next;

        return small.next;
    }
}
```

## Common Mistakes to Avoid

- Forgetting:
  ```java
  l.next = null;
  ```
  May create a cycle because nodes still point to their original next nodes.

- Returning:
  ```java
  small
  ```
  instead of:
  ```java
  small.next
  ```

- Connecting:
  ```java
  large.next = small.next
  ```
  (Wrong order)

- Creating new nodes instead of reusing existing nodes.
