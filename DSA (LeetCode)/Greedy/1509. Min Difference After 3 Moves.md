## Problem Summary
You are given an integer array `nums`.

You can perform **at most 3 moves**, where in each move you can:
```
Change any element to any value
```

Goal:
```
Minimize the difference between the maximum and minimum values
```

---

## Key Observation

Instead of modifying arbitrary elements:

```
Optimal strategy = remove (ignore) 3 elements
```

Why?

Because changing values is equivalent to **eliminating extreme values**.

---

## Core Idea

After sorting, only **4 possible scenarios** exist:

---

### Case 1: Remove 3 largest elements
```
nums[n-4] - nums[0]
```

---

### Case 2: Remove 2 largest + 1 smallest
```
nums[n-3] - nums[1]
```

---

### Case 3: Remove 1 largest + 2 smallest
```
nums[n-2] - nums[2]
```

---

### Case 4: Remove 3 smallest elements
```
nums[n-1] - nums[3]
```

---

## Why Only These 4?

Because:
```
We can remove exactly 3 elements
→ choose how many from left and right
```

Combinations:
```
(0 left, 3 right)
(1 left, 2 right)
(2 left, 1 right)
(3 left, 0 right)
```

---

## Edge Case

```
If n ≤ 4 → return 0
```

Because:
```
We can modify all elements → make them equal
```

---

## Example

Input:
```
nums = [5,3,2,4]
```

Output:
```
0
```

---

Input:
```
nums = [1,5,6,14,15]
```

Sorted:
```
[1,5,6,14,15]
```

Try all cases:
```
15-6 = 9
14-5 = 9
6-5 = 1
15-1 = 14
```

Answer:
```
1
```

---

## Java Code (Final)

```java
class Solution {
    public int minDifference(int[] nums) {
        int n = nums.length;

        if(n <= 4) return 0;

        Arrays.sort(nums);

        int min = Integer.MAX_VALUE;

        min = Math.min(nums[n - 1] - nums[3], min);
        min = Math.min(nums[n - 2] - nums[2], min);
        min = Math.min(nums[n - 3] - nums[1], min);
        min = Math.min(nums[n - 4] - nums[0], min);

        return min;
    }
}
```

## Time & Space Complexity

Time Complexity:
- O(n log n) → sorting

Space Complexity:
- O(1)

## Patterns Learned

- Sorting + greedy decision
- Reducing problem by removing extremes
- Fixed number of cases instead of brute force

---

## Common Mistakes to Avoid

- Trying all combinations (unnecessary)
- Not sorting the array
- Missing one of the 4 cases
- Not handling `n ≤ 4`

---

## Key Insight

```
Instead of modifying values,
remove extreme values strategically
```

## Mental Model

```
Shrink the range by removing worst outliers
```
