## Problem Summary
Given an integer array `nums` and an integer `k`, return `true` if:
- There exists a **continuous subarray**
- Of length **at least 2**
- Whose sum is a **multiple of k**

---

## My First Thought (Initial Approach)
- Try all subarrays and check sum

Problem:
- O(n²) → inefficient

---

## Key Observation
Instead of checking every subarray:

```
If two prefix sums have the same remainder when divided by k:
→ the subarray between them is divisible by k
```

Mathematically:

```
prefixSum[i] % k == prefixSum[j] % k
→ (prefixSum[i] - prefixSum[j]) % k == 0
```

---

## Core Idea
Track:

```
remainder = prefixSum % k
```

Use a HashMap:

```
remainder → first index where it appeared
```

---

## Final Approach (Step-by-Step in English)

1. Initialize:
   - `sum = 0`
   - HashMap: remainder → index
   - Add `(0 → -1)` to handle subarrays starting at index 0

2. Traverse array:
   - Update running sum
   - Compute `rem = sum % k`

3. If remainder already exists:
   - Check if distance ≥ 2
   - If yes → return true

4. Else:
   - Store remainder with index (only first occurrence)

5. If no valid subarray found → return false

---

## Example Walkthrough

Input:

```
nums = [23, 2, 4, 6, 7], k = 6
```

Process:

```
sum = 23 → rem = 5
sum = 25 → rem = 1
sum = 29 → rem = 5 (seen before)
distance = 2 → valid
```

Final Output:
```
true
```

---

## Java Code (Final)

```java
class Solution {
    public boolean checkSubarraySum(int[] nums, int k) {
        Map<Integer, Integer> map = new HashMap<>();
        map.put(0, -1);

        int sum = 0;

        for(int i = 0; i < nums.length; i++){
            sum += nums[i];
            int rem = sum % k;

            if(map.containsKey(rem)){
                if(i - map.get(rem) >= 2){
                    return true;
                }
            } else {
                map.put(rem, i);
            }
        }

        return false;
    }
}
```

## Common Mistakes to Avoid

- Not adding `(0 → -1)` in map
- Updating index for existing remainder
- Using `abs()` for distance
- Forgetting subarray length ≥ 2
- Treating this as sliding window problem
