## Problem Summary
You are given `trips`:

```
trips[i] = [numPassengers, from, to]
```

A car has a fixed `capacity`.

Return:
```
true  → if all trips can be completed
false → if capacity is exceeded at any point
```

---

## Key Idea

Instead of simulating each trip:

```
Use Difference Array to track passenger changes
```

---

## Core Concept

At each location:

```
+passengers at pickup point
-passengers at drop point
```

Then compute prefix sum to know:

```
current passengers at any location
```

---

## Final Approach (Step-by-Step in English)

1. Create array:
   ```
   arr[1001] (because location ≤ 1000)
   ```

2. For each trip:
   ```
   arr[from] += passengers
   arr[to]   -= passengers
   ```

3. Compute prefix sum:
   ```
   sum += arr[i]
   ```

4. If at any point:
   ```
   sum > capacity → return false
   ```

5. Otherwise:
   ```
   return true
   ```

---

## Example

Input:

```
trips = [[2,1,5],[3,3,7]], capacity = 4
```

Difference array:

```
arr[1] += 2
arr[5] -= 2

arr[3] += 3
arr[7] -= 3
```

Prefix sum:

```
index 1 → 2
index 3 → 5 ❌ exceeds capacity
```

Output:
```
false
```

---

## Java Code (Final)

```java
class Solution {
    public boolean carPooling(int[][] trips, int capacity) {
        int[] arr = new int[1001];

        for(int i = 0; i < trips.length; i++){
            int p = trips[i][0];
            int f = trips[i][1];
            int t = trips[i][2];

            arr[f] += p;
            arr[t] -= p;
        }

        int sum = 0;

        for(int i = 0; i < arr.length; i++){
            sum += arr[i];
            if(sum > capacity) return false;
        }

        return true;
    }
}
```

## Common Mistakes to Avoid

- Doing range updates (O(n²))
- Forgetting to subtract at drop point
- Not checking capacity during prefix sum
- Using wrong array size

## Key Insight

```
Mark changes, don’t simulate entire range
```
