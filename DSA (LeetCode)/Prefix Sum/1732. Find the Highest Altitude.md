## Problem Summary
A biker is going on a trip. The altitude starts at 0.

You are given an integer array `gain` where:
- `gain[i]` represents the net gain in altitude between points.

Return the **highest altitude** reached.

---

## My First Thought (Initial Approach)
- Simulate the journey step by step.
- Keep adding gains and track the maximum altitude.

---

## Key Observation
- This is a **prefix sum problem**.
- Each altitude is the sum of all previous gains.
- We start from altitude 0.

So:

```
altitude[i] = altitude[i-1] + gain[i-1]
```

---

## Final Approach (Step-by-Step in English)

1. Create a prefix array `pre` of size `n + 1`.
2. Set `pre[0] = 0` (starting altitude).
3. Traverse the gain array:
   - `pre[i] = pre[i - 1] + gain[i - 1]`
4. Traverse the prefix array to find the maximum value.
5. Return the maximum altitude.

---

## Example Walkthrough

Input:
gain = [-5, 1, 5, 0, -7]

Process:

```
pre[0] = 0
pre[1] = -5
pre[2] = -4
pre[3] = 1
pre[4] = 1
pre[5] = -6
```

Maximum:

```
max = 1
```

Final Output:
1

---

## Java Code (Final)

```java
class Solution {
    public int largestAltitude(int[] gain) {
        int[] pre = new int[gain.length + 1];
        pre[0] = 0;

        for (int i = 1; i <= gain.length; i++) {
            pre[i] = pre[i - 1] + gain[i - 1];
        }

        int max = Integer.MIN_VALUE;

        for (int i = 0; i < pre.length; i++) {
            if (max < pre[i]) {
                max = pre[i];
            }
        }

        return max;
    }
}
```

## Common Mistakes to Avoid

- Forgetting initial altitude is 0
- Off-by-one errors in prefix array
- Using gain array directly without accumulation
- Not considering negative gains properly
