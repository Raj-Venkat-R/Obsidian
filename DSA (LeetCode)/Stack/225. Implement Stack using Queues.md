## Problem Summary
Implement a stack using only queue operations.

The stack must support:

- push(x)
- pop()
- top()
- empty()

The behavior must follow **LIFO (Last In First Out)** even though queues naturally follow **FIFO (First In First Out)**.

---

## My First Thought (Initial Approach)
Queues process elements in FIFO order, while stacks require LIFO behavior.

To simulate stack behavior using queues, we need to ensure that the **most recently inserted element always appears at the front of the queue**.

---

## Key Observation
Using **two queues**, we can reorder elements during the push operation.

Steps:
- Insert the new element into the second queue.
- Move all existing elements from the first queue into the second queue.
- Swap the two queues.
- Which means the second queue is always empty.

After this process, the newest element will always be at the front of `q1`, allowing stack operations.

---

## Final Approach (Step-by-Step in English)

1. Maintain two queues:
   - `q1` → main queue storing elements in stack order
   - `q2` → temporary queue used during push

2. Push operation:
   - Insert element into `q2`
   - Move all elements from `q1` into `q2`
   - Swap `q1` and `q2`

3. Pop operation:
   - Remove element from `q1`

4. Top operation:
   - Return the front element of `q1`

5. Empty operation:
   - Check if `q1` is empty

## Java Code (Final)

```java
class MyStack {

    Queue<Integer> q1;
    Queue<Integer> q2;

    public MyStack() {
        q1 = new LinkedList<>();
        q2 = new LinkedList<>();
    }
    
    public void push(int x) {
        q2.offer(x);

        while (!q1.isEmpty()) {
            q2.offer(q1.poll());
        }

        Queue<Integer> temp = q1;
        q1 = q2;
        q2 = temp;
    }
    
    public int pop() {
        return q1.poll();
    }
    
    public int top() {
        return q1.peek();
    }
    
    public boolean empty() {
        return q1.isEmpty();
    }
}
```
