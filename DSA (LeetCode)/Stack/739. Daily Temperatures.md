# LeetCode 739 – Daily Temperatures

## Problem Summary

Given:
`temperatures[i]` = temperature on day i

For each day:
Find how many days until a **warmer temperature**.

If no warmer day exists → return 0.

---

## Key Insight

Unlike 496, here we must return **distance between indices**.

So we store **indices in the stack**, not values.

---

## Core Idea

Use a **monotonically decreasing stack (by temperature)**.

Traverse from **right to left**.

---

## Why Store Indices?

Because we need:

```
result[i] = stack.peek() - i
```

If we stored only temperature values,
we could not compute the number of days difference.

---

## Algorithm

For each index i (from right to left):

1. While stack not empty AND  
   `temperatures[stack.peek()] <= temperatures[i]`
   → pop
2. If stack empty → result[i] = 0
3. Else → result[i] = stack.peek() - i
4. Push current index into stack

---

## Your Implementation

```java
class Solution {
    public int[] dailyTemperatures(int[] temperatures) {
        Stack<Integer> stack = new Stack<>();
        int[] res = new int[temperatures.length];

        for(int i = temperatures.length - 1; i >= 0; i--){
            while(!stack.isEmpty() && 
                  temperatures[stack.peek()] <= temperatures[i]){
                stack.pop();
            }

            if(stack.isEmpty()){
                res[i] = 0;
            } else {
                res[i] = stack.peek() - i;
            }

            stack.push(i);
        }

        return res;
    }
}
```

---

## Complexity

Time Complexity: **O(n)**  
Space Complexity: **O(n)**

Each index is pushed once and popped at most once.

---

## Core Mental Model

Stack stores indices of days that are still waiting to find a warmer day.

When a warmer temperature appears, it resolves previous colder days in one pass.
