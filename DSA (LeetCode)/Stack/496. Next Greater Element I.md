# LeetCode 496 – Next Greater Element I

## Problem Summary

Given:
- `nums1`
- `nums2`

All elements of `nums1` exist inside `nums2`.

For each element in `nums1`, find its **next greater element in nums2**.
If none exists, return -1.

---

## Core Idea

Instead of solving for `nums1` directly:

1. Precompute **Next Greater Element for all elements in nums2**.
2. Store mapping:  
   `value → next greater value`
3. Lookup answers for `nums1`.

This reduces brute force O(n1 × n2) to **O(n1 + n2)**.

---

## Monotonic Stack Pattern

We use a **monotonically decreasing stack**.

Traverse `nums2` from **right to left**.

### Algorithm

For each element in nums2:

1. While stack not empty AND `stack.peek() <= current`
   → pop
2. If stack empty → next greater = -1
3. Else → next greater = stack.peek()
4. Store mapping in HashMap
5. Push current into stack

---

## Your Implementation

```java
class Solution {
    public int[] nextGreaterElement(int[] nums1, int[] nums2) {
        Stack<Integer> stack = new Stack<>();
        Map<Integer, Integer> map = new HashMap<>();

        for(int i : nums2){
            map.put(i, -1);
        }

        for(int i = nums2.length - 1; i >= 0; i--){
            while(!stack.isEmpty() && stack.peek() <= nums2[i]){
                stack.pop();
            }

            if(!stack.isEmpty()){
                map.put(nums2[i], stack.peek());
            }

            stack.push(nums2[i]);
        }

        int[] res = new int[nums1.length];

        for(int i = 0; i < nums1.length; i++){
            res[i] = map.get(nums1[i]);
        }

        return res;
    }
}
```

---

## Complexity

Time Complexity: **O(n1 + n2)**  
Space Complexity: **O(n2)**

Each element is pushed once and popped at most once.

---

## Core Mental Model

Stack stores elements still waiting for their next greater value.

When a larger element appears, it resolves smaller elements immediately.
