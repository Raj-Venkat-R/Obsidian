## Problem Summary
Given a string `s` containing only `'('` and `')'`, find the length of the **longest valid (well-formed) parentheses substring**.

---

## Key Idea
Use a **stack to store indices** (not characters).

Track the **last unmatched index** to compute valid substring lengths.

---

## Why Stack Stores Indices
Instead of storing characters:

```
We store indices to calculate length using:
length = currentIndex - lastInvalidIndex
```

---

## Final Approach (Step-by-Step in English)

1. Initialize stack:
   ```
   push -1 (base index)
   ```

2. Traverse string:
   - If `'('`:
     ```
     push index
     ```
   - If `')'`:
     ```
     pop once
     ```

3. After popping:
   - If stack becomes empty:
     ```
     push current index (new base)
     ```
   - Else:
     ```
     max = max(max, i - stack.peek())
     ```

---

## Why Push `-1` Initially

Acts as a **base index**.

Example:

```
"()"
i = 1 → length = 1 - (-1) = 2
```

---

## Why Push Index When Stack Becomes Empty

Indicates:
```
Invalid closing bracket → reset starting point
```

Example:

```
")()"
i = 0 → push 0 → new base
```

---

## Example Walkthrough

Input:

```
s = ")()())"
```

Steps:

```
stack = [-1]

i=0 ')' → pop → empty → push 0
i=1 '(' → push 1
i=2 ')' → pop → stack = [0]
length = 2 - 0 = 2

i=3 '(' → push 3
i=4 ')' → pop → stack = [0]
length = 4 - 0 = 4
```

Output:

```
4
```

---

## Java Code (Final)

```java
class Solution {
    public int longestValidParentheses(String s) {
        Stack<Integer> stack = new Stack<>();
        stack.push(-1);

        int max = 0;

        for(int i = 0; i < s.length(); i++){
            char ch = s.charAt(i);

            if(ch == '('){
                stack.push(i);
            } else {
                stack.pop();

                if(stack.isEmpty()){
                    stack.push(i);
                } else {
                    max = Math.max(max, i - stack.peek());
                }
            }
        }

        return max;
    }
}
```

## Patterns Learned

- Stack with index tracking
- Boundary reset using base index
- Length calculation using indices

---

## Common Mistakes to Avoid

- Using characters instead of indices
- Forgetting to push `-1` initially
- Wrong subtraction (`peek - i`)
- Not handling empty stack after pop
- Trying to match multiple bracket types (not needed)

---

## Alternative Approach

Dynamic Programming (DP):

```
dp[i] = length of longest valid substring ending at i
```

## Key Insight

