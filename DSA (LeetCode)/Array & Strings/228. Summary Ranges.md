## Problem Summary
You are given a **sorted unique integer array** `nums`.

Return the **smallest sorted list of ranges** that cover all numbers in the array exactly.

A range should be formatted as:
- `"a"` if the range contains only one number
- `"a->b"` if the range contains multiple numbers

---

## My First Thought (Initial Approach)
- Traverse the array and check whether the next number continues the sequence.
- If numbers are consecutive, extend the range.
- If not, close the current range and start a new one.

---

## Key Observation
- The array is **sorted and unique**, so consecutive numbers satisfy:

```
nums[i + 1] == nums[i] + 1
```

- Each range begins at a `start` value.
- Move forward until the sequence breaks.
- Then record the range.

---

## Final Approach (Step-by-Step in English)

1. Initialize an empty list `r` to store the ranges.
2. Traverse the array using index `i`.
3. Store the current number as `start`.
4. Continue moving `i` while the next number is consecutive.
5. When the sequence stops:
   - If `start == nums[i]`, add `"start"`
   - Otherwise add `"start->nums[i]"`
6. Continue until the array ends.

---

## Example Walkthrough

Input:

```
nums = [0,1,2,4,5,7]
```

Process:

- Start at `0`, consecutive until `2` → `"0->2"`
- Start at `4`, consecutive until `5` → `"4->5"`
- Start at `7`, single element → `"7"`

Final Output:

```
["0->2","4->5","7"]
```

---

## Java Code (Final)

```java
class Solution {
    public List<String> summaryRanges(int[] nums) {
        List<String> r = new ArrayList<>();

        for (int i = 0; i < nums.length; i++) {
            int start = nums[i];

            while (i + 1 < nums.length && nums[i + 1] == nums[i] + 1) {
                i++;
            }

            if (start == nums[i]) {
                r.add(String.valueOf(start));
            } else {
                r.add(start + "->" + nums[i]);
            }
        }

        return r;
    }
}
```

## Common Mistakes to Avoid

- Forgetting to check `i + 1 < nums.length`
- Not updating `i` correctly inside the loop
- Missing the single element range case
- Using unnecessary extra pointers
