## Problem Summary
Given an integer `n`, generate an `n x n` matrix filled with numbers from:

```
1 → n²
```

in **spiral order**.

---

## Key Idea
Use **4 boundaries** to simulate spiral filling:

- `top`
- `bottom`
- `left`
- `right`

Fill layer by layer while shrinking boundaries.

---

## Final Approach (Step-by-Step in English)

1. Initialize:
   - `top = 0`, `bottom = n - 1`
   - `left = 0`, `right = n - 1`
   - `num = 1`

2. Loop while:
   ```
   top <= bottom AND left <= right
   ```

3. Fill in 4 directions:

   - Left → Right (top row)
   - Top → Bottom (right column)
   - Right → Left (bottom row) → if valid
   - Bottom → Top (left column) → if valid

4. Increment `num` after each placement

5. Shrink boundaries after each step

## Java Code (Final)

```java
class Solution {
    public int[][] generateMatrix(int n) {
        int[][] res = new int[n][n];

        int top = 0, bottom = n - 1;
        int left = 0, right = n - 1;

        int num = 1;

        while(top <= bottom && left <= right){

            for(int i = left; i <= right; i++){
                res[top][i] = num++;
            }
            top++;

            for(int i = top; i <= bottom; i++){
                res[i][right] = num++;
            }
            right--;

            if(top <= bottom){
                for(int i = right; i >= left; i--){
                    res[bottom][i] = num++;
                }
                bottom--;
            }

            if(left <= right){
                for(int i = bottom; i >= top; i--){
                    res[i][left] = num++;
                }
                left++;
            }
        }

        return res;
    }
}
```
