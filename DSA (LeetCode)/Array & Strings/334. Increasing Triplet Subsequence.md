## Problem Summary
Given an integer array `nums`, return:

```
true  → if there exists i < j < k such that
         nums[i] < nums[j] < nums[k]

false → otherwise
```

---

## Key Idea

We don’t need the full subsequence.

```
We only need to track the smallest possible candidates
```

---

## Core Concept

Maintain two variables:

```
first  → smallest value so far
second → second smallest value so far
```

---

## Final Approach (Step-by-Step in English)

1. Initialize:
   ```
   first = ∞
   second = ∞
   ```

2. Traverse array:
   - If `num <= first`:
     ```
     update first
     ```
   - Else if `num <= second`:
     ```
     update second
     ```
   - Else:
     ```
     num > second → triplet found → return true
     ```

---

## Why This Works

We maintain:

```
first < second < current number
```

Once a number is greater than `second`, we have:

```
valid increasing triplet
```

---

## Example

Input:

```
[2,1,5,0,4,6]
```

Steps:

```
first = 2
first = 1
second = 5
first = 0
second = 4
6 > 4 → triplet found
```

Output:

```
true
```

---

## Edge Case

Input:

```
[5,4,3,2,1]
```

Explanation:

```
Always decreasing → no increasing triplet
```

Output:

```
false
```

---

## Java Code (Final)

```java
class Solution {
    public boolean increasingTriplet(int[] nums) {

        int first = Integer.MAX_VALUE;
        int second = Integer.MAX_VALUE;

        for(int num : nums){

            if(num <= first){
                first = num;
            }
            else if(num <= second){
                second = num;
            }
            else{
                return true;
            }
        }

        return false;
    }
}
```

- Sorting (destroys order)
- Using sliding window
- Confusing subsequence with subarray
