## Problem Summary
Given an array `nums` and integer `k`, rotate the array to the **right by k steps**.

---

## Key Idea

Instead of shifting elements one by one:

```
Use reverse operations
```

---

## Core Trick

To rotate right by `k`:

1. Reverse entire array  
2. Reverse first `k` elements  
3. Reverse remaining elements  

---

## Why this works

Example:

```
nums = [1,2,3,4,5,6,7], k = 3
```

---

### Step 1: Reverse whole array

```
[7,6,5,4,3,2,1]
```

---

### Step 2: Reverse first k

```
[5,6,7,4,3,2,1]
```

---

### Step 3: Reverse rest

```
[5,6,7,1,2,3,4]
```

---

## Important Step

```
k = k % n
```

Why?
```
Avoid unnecessary full rotations
```

---

## Java Code (Final)

```java
class Solution {
    public void rotate(int[] nums, int k) {
        k = k % nums.length;

        reverse(nums, 0, nums.length - 1);
        reverse(nums, 0, k - 1);
        reverse(nums, k, nums.length - 1);
    }

    private void reverse(int[] nums, int left, int right){
        while(left < right){
            int temp = nums[left];
            nums[left++] = nums[right];
            nums[right--] = temp;
        }
    }
}
```

## Time & Space Complexity

Time:
```
O(n)
```

Space:
```
O(1)
```

## Patterns Learned

- Array reversal technique
- In-place transformation
- Breaking problem into steps

---

## Common Mistakes

- Forgetting `k % n`
- Wrong indices in reverse
- Swapping incorrectly
- Using extra space unnecessarily

---

## Key Insight

```
Reverse → fix order in parts → get rotation
```

---

## Alternative Approaches

1. Extra array → O(n) space  
2. Cyclic replacements (harder)  
3. Brute force shifting → O(n*k) ❌  

---

## Mental Model

```
Move last k elements to front
```
