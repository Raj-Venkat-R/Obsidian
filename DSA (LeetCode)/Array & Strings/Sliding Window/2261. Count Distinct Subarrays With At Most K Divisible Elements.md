## Problem Summary
Given an array `nums`, integers `k` and `p`, count the number of **distinct subarrays** such that:
- At most `k` elements in the subarray are divisible by `p`

Return the number of distinct subarrays.

---

## Key Idea
- Generate all subarrays starting at each index
- Track how many elements are divisible by `p`
- Stop expanding when count exceeds `k`
- Store each valid subarray in a set to ensure uniqueness

---

## Final Approach (Step-by-Step in English)

1. Initialize a HashSet to store unique subarrays
2. For each starting index `i`:
   - Initialize `count = 0`
   - Use a StringBuilder to build subarray representation
3. For each ending index `j` from `i`:
   - If `nums[j] % p == 0`, increment `count`
   - If `count > k`, break
   - Append element to builder
   - Add current subarray string to set
4. Return size of set

---

## Example

Input:
```
nums = [2,3,3,2,2], k = 2, p = 2
```

Output:
```
11
```

---

## Java Code (Final)

```java
class Solution {
    public int countDistinct(int[] nums, int k, int p) {
        Set<String> set = new HashSet<>();

        for(int i = 0; i < nums.length; i++){
            int count = 0;
            StringBuilder sb = new StringBuilder();

            for(int j = i; j < nums.length; j++){
                if(nums[j] % p == 0) count++;
                if(count > k) break;

                sb.append(nums[j]).append(",");
                set.add(sb.toString());
            }
        }

        return set.size();
    }
}
```

## Time & Space Complexity

Time Complexity:
- O(n² * L) where L = average subarray length (due to string building)

Space Complexity:
- O(n² * L) for storing distinct subarrays

---

## Patterns Learned

- Brute force subarray generation
- Early stopping using constraints
- HashSet for deduplication
- String encoding of subarrays

---

## Common Mistakes to Avoid

- Not breaking when count > k
- Forgetting to reset StringBuilder per `i`
- Missing delimiter → causes ambiguity (e.g., [1,23] vs [12,3])
- Using list instead of set → duplicates counted
