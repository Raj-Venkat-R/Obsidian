## Problem Summary
Given an integer array `nums` and an integer `k`, return the number of **subarrays with exactly `k` distinct elements**.

---

## Key Observation
Directly counting **exactly K distinct** is difficult.

Instead, use:

```
exactly(K) = atMost(K) - atMost(K-1)
```

---

## Why This Works

- `atMost(K)` → subarrays with ≤ K distinct
- `atMost(K-1)` → subarrays with ≤ K-1 distinct

Subtracting removes all smaller cases, leaving:

```
only subarrays with exactly K distinct
```

---

## Final Approach (Step-by-Step in English)

1. Create helper function:
   ```
   help(k) → number of subarrays with at most k distinct
   ```

2. Use sliding window:
   - Maintain frequency map
   - Expand `right`
   - Shrink `left` if distinct > k

3. Count valid subarrays:
   ```
   count += (right - left + 1)
   ```

4. Final answer:
   ```
   help(k) - help(k-1)
   ```

---

## Example Walkthrough

Input:

```
nums = [1,2,1,2,3], k = 2
```

```
atMost(2) = many subarrays
atMost(1) = fewer subarrays
```

Subtract:

```
exactly(2) = 7
```

## Java Code (Final)

```java
class Solution {
    public int subarraysWithKDistinct(int[] nums, int k) {
        return help(nums, k) - help(nums, k - 1);
    }

    private int help(int[] arr, int k){
        Map<Integer, Integer> map = new HashMap<>();
        int left = 0;
        int count = 0;

        for(int right = 0; right < arr.length; right++){

            map.put(arr[right], map.getOrDefault(arr[right], 0) + 1);

            while(map.size() > k){
                map.put(arr[left], map.get(arr[left]) - 1);
                if(map.get(arr[left]) == 0){
                    map.remove(arr[left]);
                }
                left++;
            }

            count += (right - left + 1);
        }

        return count;
    }
}
```

## Common Mistakes to Avoid

- Trying to count exactly K directly
- Using `if(map.size() == k)` (wrong)
- Forgetting subtraction trick
- Not shrinking window properly
