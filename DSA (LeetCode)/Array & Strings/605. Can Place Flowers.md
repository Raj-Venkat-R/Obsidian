## Problem Summary
You are given a flowerbed array where:
- `0` → empty plot
- `1` → already planted

You cannot plant flowers in adjacent plots.

Given an integer `n`, return `true` if you can plant `n` new flowers without violating the rule.

---

## My First Thought (Initial Approach)
- Try placing a flower at every position.
- Check left and right neighbors.
- Count how many flowers can be placed.

---

## Key Observation
A flower can be planted at index `i` if:

```
flowerbed[i] == 0
left == 0
right == 0
```

Where:
- `left = flowerbed[i-1]` (or 0 if i == 0)
- `right = flowerbed[i+1]` (or 0 if i is last index)

Once planted:
- Mark position as `1`
- Skip next index to avoid adjacency

---

## Final Approach (Step-by-Step in English)

1. Initialize `count = 0`.
2. Traverse the array:
   - If current position is empty:
     - Check left and right neighbors
     - If both are empty:
       - Plant flower (`flowerbed[i] = 1`)
       - Increment count
       - Skip next index (`i++`)
3. After traversal:
   - Return `count >= n`

---

## Example Walkthrough

Input:
flowerbed = [1,0,0,0,1]  
n = 1

Process:

```
i = 0 → skip (already 1)

i = 1 → left = 1 → cannot plant

i = 2 → left = 0, right = 0 → plant
flowerbed becomes [1,0,1,0,1]
count = 1
skip next index

Result:
count >= n → true
```

---

## Java Code (Final)

```java
class Solution {
    public boolean canPlaceFlowers(int[] flowerbed, int n) {
        int count = 0;

        for (int i = 0; i < flowerbed.length; i++) {
            if (flowerbed[i] == 0) {
                
                int left = (i == 0) ? 0 : flowerbed[i - 1];
                int right = (i == flowerbed.length - 1) ? 0 : flowerbed[i + 1];

                if (left == 0 && right == 0) {
                    flowerbed[i] = 1; 
                    count++;
                    i++; 
                }
            }
        }

        return count >= n;
    }
}
```

- Modifying array incorrectly
