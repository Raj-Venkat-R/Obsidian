## Problem Summary
Given an `m x n` matrix, return all elements in **spiral order**.

Traversal order:
- Left → Right
- Top → Bottom
- Right → Left
- Bottom → Top

Repeat until all elements are visited.

---

## Key Idea
Maintain **4 boundaries**:
- `top`
- `bottom`
- `left`
- `right`

Shrink boundaries after each traversal.

---

## Final Approach (Step-by-Step in English)

1. Initialize:
   - `top = 0`
   - `bottom = rows - 1`
   - `left = 0`
   - `right = cols - 1`

2. Loop while:
   ```
   top <= bottom AND left <= right
   ```

3. Traverse in 4 directions:

   - Left → Right (top row)
   - Top → Bottom (right column)
   - Right → Left (bottom row) → only if `top <= bottom`
   - Bottom → Top (left column) → only if `left <= right`

4. After each traversal:
   - Shrink boundaries

## Example Walkthrough

Input:

```
matrix = [

]
```

```
[1,2,3,6,9,8,7,4,5]
```

## Java Code (Final)

```java
class Solution {
    public List<Integer> spiralOrder(int[][] matrix) {
        int top = 0;
        int left = 0;
        int bottom = matrix.length - 1;
        int right = matrix[0].length - 1;

        List<Integer> res = new ArrayList<>();

        while(top <= bottom && left <= right){

            for(int i = left; i <= right; i++){
                res.add(matrix[top][i]);
            }
            top++;

            for(int i = top; i <= bottom; i++){
                res.add(matrix[i][right]);
            }
            right--;

            if(top <= bottom){
                for(int i = right; i >= left; i--){
                    res.add(matrix[bottom][i]);
                }
                bottom--;
            }

            if(left <= right){
                for(int i = bottom; i >= top; i--){
                    res.add(matrix[i][left]);
                }
                left++;
            }
        }

        return res;
    }
}
```

## Common Mistakes to Avoid

- Forgetting boundary checks (`top <= bottom`, `left <= right`)
- Double counting rows/columns
- Wrong order of traversal
- Not updating boundaries correctly
