# JavaScript Fundamentals

## Overview
This note covers foundational JavaScript concepts learned through building a counter app:
- Variables and data types
- DOM manipulation
- Functions and events
- Scope
- Conditional statements
- Operators

---

# 1. Variables

## Definition
Variables are used to store data.

```js
let count = 0;
const name = "Raj";
```

## Key Points
- `let` → value can change
- `const` → cannot be reassigned
- JavaScript is dynamically typed

```js
let x = 10;
x = "hello";
```

---

# 2. Data Types

Basic types:
- Number → `10`
- String → `"text"`
- Boolean → `true / false`

```js
let num = 5;
let str = "hello";
let flag = true;
```

---

# 3. DOM (Document Object Model)

## Definition
The DOM is a tree of objects created by the browser from HTML.

Each HTML element becomes a JavaScript object.

---

## Selecting Elements

```js
let countEl = document.getElementById("count-el");
```

Returns a DOM element object.

---

## Updating Content

```js
countEl.innerText = count;
countEl.textContent = count;
```

### innerText vs textContent

| Feature        | innerText       | textContent     |
|----------------|----------------|-----------------|
| Visible text   | Yes            | Yes             |
| Hidden text    | No             | Yes             |
| CSS aware      | Yes            | No              |
| Performance    | Slower         | Faster          |

Preferred:
```js
countEl.textContent = count;
```

# 4. Functions

## Definition
Reusable blocks of code.

```js
function increment() {
    count++;
}
```

---

# 5. Events

## Definition
User actions that trigger JavaScript.

### Using addEventListener

```js
let btn = document.getElementById("button");

btn.addEventListener("click", increment);
```

Important:
- `increment` → pass function
- `increment()` → executes immediately (wrong in events)

# 6. Counter App Logic

## State and UI

- `count` → state
- DOM → UI

## Flow

User Action → Function → Update State → Update UI

```js
let count = 0;
let countEl = document.getElementById("count-el");

function increment() {
    count++;
    countEl.textContent = count;
}
```

---

# 7. Scope

## Definition
Scope determines where variables are accessible.

### Local Scope

```js
function test() {
    let x = 10;
}
console.log(x); // error
```

### Global Scope

```js
let x = 10;

function test() {
    console.log(x);
}
```

Rule:
Variables inside functions are not accessible outside.

# 8. Conditional Statements (if-else)

## Syntax

```js
if (condition) {
    // code
} else {
    // code
}
```

## Example

```js
if (count > 0) {
    console.log("Positive");
} else {
    console.log("Zero or Negative");
}
```

---

## else if

```js
if (count > 0) {
    // ...
} else if (count === 0) {
    // ...
} else {
    // ...
}
```

---

## Truthy and Falsy

Falsy values:
- `0`
- `""`
- `null`
- `undefined`
- `NaN`
- `false`

```js
if (0) {
    // won't run
}
```

# 9. Operators

## Arithmetic Operators

```js
+  -  *  /  %  ++  --
```

---

## Assignment Operators

```js
=  +=  -=  *=  /=  %=
```

---

## Comparison Operators

```js
==   // loose equality
===  // strict equality
!=
!== 
>  <  >=  <=
```

Preferred:
```js
===
```

---

## Logical Operators

```js
&&  // AND
||  // OR
!   // NOT
```

### Examples

```js
if (count > 0 && count < 10)
if (count === 0 || count === 10)
if (!isRunning)
```

---

## Unary Operators

```js
typeof
++
--
!
```

---

## Ternary Operator

```js
condition ? value1 : value2;
```

Example:

```js
let result = count > 0 ? "Positive" : "Zero";
```

---

## String Concatenation


# 11. Common Mistakes

## Incorrect variable usage

```js
increment-btn // invalid
```

Correct:

```js
let incrementBtn = document.getElementById("increment-btn");
```

---

## Calling function instead of passing

```js
btn.addEventListener("click", error()); // wrong
```

Correct:

```js
btn.addEventListener("click", error);
```

---

## Typo errors

```js
documnet // wrong
document // correct
```

---

## Mixing event styles

Avoid:
- inline `onclick`
- `addEventListener`

Use only one (prefer `addEventListener`)
