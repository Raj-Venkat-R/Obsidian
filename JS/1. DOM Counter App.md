# 🧠 JavaScript Basics (Counter App Learning)

## 📌 Overview
This note covers the foundational JavaScript concepts learned while building a simple **Passenger Counter App**, focusing on:
- Variables
- DOM manipulation
- Events
- Functions
- Scope

---

# 🧩 1. Variables (let, const)

## 🔹 Definition
Variables are used to store data.

```js
let count = 0;
const name = "Raj";
```

## 🔹 Key Points
- `let` → value can change
- `const` → value cannot be reassigned
- JavaScript is **dynamically typed** (no need to specify type)

```js
let x = 10;     // number
x = "hello";    // now string
```

---

# 🧩 2. Data Types (Basic)

- Number → `10`
- String → `"hello"`
- Boolean → `true / false`

```js
let num = 5;
let text = "hi";
let flag = true;
```

---

# 🧩 3. Operators

Used to perform operations:

```js
count = count + 1;
count++;
count--;
```

---

# 🧩 4. Functions

## 🔹 Definition
Reusable blocks of code.

```js
function increment() {
    count++;
}
```

## 🔹 Purpose
- Avoid repetition
- Trigger logic on events

---

# 🧩 5. DOM (Document Object Model)

## 🔹 Definition
> The DOM is a tree of objects created by the browser from HTML.

Each HTML element becomes a **JavaScript object**.

---

## 🔹 Selecting Elements

```js
let countEl = document.getElementById("count-el");
```

- Returns a **DOM element object**
- Not just text or ID

---

## 🔹 Updating UI

```js
countEl.innerText = count;
```

- Updates visible content on the page

---

# 🧩 6. Events (Core Concept)

## 🔹 Definition
User actions that trigger JavaScript.

### ❌ Inline (not recommended)
```html
<button onclick="increment()">+</button>
```

### ✅ Preferred
```js
button.addEventListener("click", increment);
```

---

# 🧩 7. Counter App Logic

## 🔹 State + UI

- `count` → state (data)
- DOM (`innerText`) → UI

## 🔹 Flow

```
User Click → Function → Update count → Update UI
```

---

## 🔹 Example

```js
let count = 0;
let countEl = document.getElementById("count-el");

function increment() {
    count++;
    countEl.innerText = count;
}
```

---

# 🧩 8. Scope

## 🔹 Definition
Where a variable can be accessed.

### ❌ Local Scope
```js
function test() {
    let x = 10;
}
console.log(x); // error
```

### ✅ Global Scope
```js
let x = 10;

function test() {
    console.log(x); // works
}
```

---

## 🔹 Important Rule

> Variables inside functions are NOT accessible outside

---

# 🧩 9. Script Loading

## ❌ Problem

```html
<script src="index.js"></script>
```

- JS may run before HTML loads

---

## ✅ Solution

### Option 1
```html
<script src="index.js" defer></script>
```

### Option 2
Place script at bottom of body

---

# 🧩 10. Common Mistakes

## ❌ Using ID as variable

```js
increment-btn // ❌ invalid
```

## ✅ Correct

```js
let incrementBtn = document.getElementById("increment-btn");
```

---

## ❌ Repeated DOM access

```js
document.getElementById("count-el")
```

## ✅ Store once

```js
let countEl = document.getElementById("count-el");
```

---

## ❌ Mixing event styles

- `onclick` + `addEventListener`

## ✅ Use one (prefer JS)

---
