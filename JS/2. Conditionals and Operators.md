# JavaScript Fundamentals

## Overview
This note covers:
- Conditional statements
- Truthy and falsy values
- Operators in JavaScript

---

# 1. Conditional Statements (if-else)

## Syntax

```js
if (condition) {
    // code
} else {
    // code
}
```

## Example

```js
if (count > 0) {
    console.log("Positive");
} else {
    console.log("Zero or Negative");
}
```

---

## else if

```js
if (count > 0) {
    // ...
} else if (count === 0) {
    // ...
} else {
    // ...
}
```

---

## Truthy and Falsy

### Falsy values:
- `0`
- `""`
- `null`
- `undefined`
- `NaN`
- `false`

```js
if (0) {
    // won't run
}
```

### Truthy:
Any value not listed above is truthy.

# 2. Operators

## Arithmetic Operators

```js
+  -  *  /  %  ++  --
```

---

## Assignment Operators

```js
=  +=  -=  *=  /=  %=
```

---

## Comparison Operators

```js
==   // loose equality (type conversion)
===  // strict equality (no conversion)
!=
!== 
>  <  >=  <=
```

Preferred:
```js
===
```

---

## Logical Operators

```js
&&  // AND
||  // OR
!   // NOT
```

### Examples

```js
if (count > 0 && count < 10)
if (count === 0 || count === 10)
if (!isRunning)
```

---

## Unary Operators

```js
typeof
++
--
!
```

---

## Ternary Operator

```js
condition ? value1 : value2;
```

### Example

```js
let result = count > 0 ? "Positive" : "Zero";
```

---

## String Concatenation

```js
"Hello" + " World"
```

---

# Key Takeaways

- Conditional statements control program flow
- Truthy and falsy values affect condition evaluation
- Use strict equality (`===`) to avoid unexpected behavior
- Logical operators combine conditions effectively
- Operators are essential for calculations and decisions
