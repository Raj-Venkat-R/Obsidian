# 8051 Embedded C Program to Toggle P1.0 Every 10ms

## Given:
Crystal Frequency (XTAL) = 11.0592 MHz

---

# Timer Calculation (4 Marks)

## 1. Machine Cycle Frequency

In 8051:

Machine Cycle Frequency = Crystal Frequency / 12  

= 11.0592 MHz / 12  
= 921.6 kHz  

Time per machine cycle:

= 1 / 921600  
= 1.085 µs

---

## 2. Counts Required for 10ms Delay

10 ms = 10000 µs  

Counts required:

= 10000 / 1.085  
= 9216 counts

---

## 3. Timer Initial Value Calculation

Using Timer0 Mode1 (16-bit)

Maximum count = 65536  

Initial Value = 65536 – 9216  
= 56320  

Convert 56320 to hexadecimal:

56320₁₀ = DC00H

So,

- TH0 = DCH  
- TL0 = 00H  

---

# Embedded C Program (6 Marks)

```c
#include <reg51.h>
void delay_10ms();
sbit LED = P1^0;   // Define P1.0 as LED
void main()
{
    while(1)
    {
        LED = 1;          // Turn ON
        delay_10ms();       
        LED = 0;          // Turn OFF
        delay_10ms();
    }
}
void delay_10ms()
{
    TMOD = 0x01;      // Timer0 Mode1 (16-bit)
    TH0 = 0xDC;       // Load high byte
    TL0 = 0x00;       // Load low byte
    TR0 = 1;          // Start Timer0
    while(TF0 == 0);  // Wait until timer overflows
    TR0 = 0;          // Stop timer
    TF0 = 0;          // Clear overflow flag
}
```
