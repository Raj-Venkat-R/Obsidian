# Architecture and Functions of Data Warehouse (Laymen Format)

## Introduction

A **Data Warehouse** is a central storage system where large amounts of data from different sources are collected, stored, and organized for analysis and decision making.

In simple words,  
👉 A data warehouse is like a **big storage room** where all company data is kept in a clean and organized way so that managers can easily analyze it.

---

# Architecture of Data Warehouse (4 Marks)

The architecture of a data warehouse mainly has **three layers**:

---

## 1. Data Source Layer (Bottom Layer)

This is where data comes from.

✔ Databases  
✔ Excel files  
✔ ERP systems  
✔ CRM systems  
✔ Online transactions  

Example:  
Sales data from billing software, customer data from CRM.

---

## 2. ETL Layer (Middle Layer)

ETL means:

- **E – Extract** (Collect data from sources)  
- **T – Transform** (Clean and format data)  
- **L – Load** (Store data into warehouse)

This layer cleans the messy data and converts it into a proper format.

Example:  
Removing duplicate customer records before storing.

---

## 3. Data Warehouse & Presentation Layer (Top Layer)

This is where cleaned data is stored and used.

✔ Data Warehouse Database  
✔ Data Marts (small subject-based storage)  
✔ BI Tools & Dashboards  

Managers use this layer to view reports and make decisions.

Example:  
Monthly sales dashboard in Power BI.

---

### Simple Architecture Flow:

Data Sources → ETL Process → Data Warehouse → Reports & Dashboards

---

# Functions of Data Warehouse (6 Marks)

A data warehouse performs many important functions:

---

## 1. Data Integration

It combines data from different departments (sales, HR, finance) into one place.

---

## 2. Data Storage

It stores large amounts of historical data for many years.

Example:  
Company can check 5 years old sales data.

---

## 3. Data Cleaning

It removes errors, duplicates, and incomplete records.

---

## 4. Supports Analysis and Reporting

Helps in generating reports, charts, and dashboards.

Example:  
Quarterly profit report.

---

## 5. Supports Decision Making

Managers use warehouse data to make strategic decisions.

Example:  
Deciding which product to promote.

---

## 6. Trend and Forecast Analysis

Helps to identify patterns and predict future outcomes.

Example:  
Predicting next year's sales based on past data.

---

# Conclusion

A Data Warehouse is a centralized system that collects, cleans, and stores data from different sources. Its architecture includes data sources, ETL process, and storage/reporting layers. Its main functions are integration, storage, cleaning, analysis, and supporting decision making.
