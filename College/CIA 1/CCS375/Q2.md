# JavaScript Arrays

## Introduction

- Array is a grouping of objects.  
- It stores multiple values in a single variable.  
- It stores a fixed-size sequential collection of elements of the same type.  
- It is used to store collection of data.  

In simple words, an array is like a container that holds multiple values under one name instead of creating many separate variables.

---

## Creating and Initializing Arrays

```javascript
var variable_name = new Array();   // Creating an Array
var arr = [];                     // Creating an Array
var arr1 = [1, 2, 3];              // Initializing an Array
```

Arrays can be created using the `new Array()` constructor or using square brackets `[ ]`.

---

## Multidimensional Array

```javascript
var arr2 = [
    [1, 2, 3],
    ['a', 'b', 'c'],
    ['x', 'y', 'z']
];
```

A multidimensional array is an array inside another array.  
It is useful for storing data in table format (rows and columns).

---

## Iteration through Arrays

```javascript
function show_array(arr)
{
    for (var i = 0; i < arr.length; i++)
    {
        document.write(arr[i]);
        document.write('<br/>');
    }
}

var arr1 = [1, 2, 3];
show_array(arr1);
```

Iteration means accessing each element one by one using loops.  
The `length` property is used to control the loop.

---

## Indexing in Array

- Array elements are accessed using index numbers.
- Index starts from 0.
- First element → index 0
- Second element → index 1

Example:

```javascript
var arr = ["Apple", "Banana", "Mango"];
document.write(arr[0]);   // Apple
```

If we access a non-existing index, it returns `undefined`.

---

## Important Characteristics of JavaScript Arrays

- Arrays are dynamic (size can increase or decrease).
- They can store different data types.
- Length changes automatically.
- Elements are stored in sequential order.

Example:

```javascript
var arr = [1, "Hello", true];
```

## Array Properties

| Array Properties | Description |
|------------------|-------------|
| Constructor | It returns a reference to the array function that created the object. |
| Index | It represents the zero-based index of the match in the string. |
| Length | It reflects the number of elements in an array. |

## Array Methods

| Methods | Description |
|----------|-------------|
| concat() | It returns a new array comprised of this array joined with other arrays and values. |
| every() | It returns true if every element in this array satisfies the provided testing function. |
| filter() | It creates a new array with all the elements of this array for which the provided filtering function returns true. |
| indexOf() | It returns the first index of an element within the array equal to the specified value. |
| join() | It joins all elements of an array into a string. |
| pop() | It removes the last element from an array and returns that element. |
| push() | It adds one or more elements to the end of an array and returns the new length of the array. |
| reverse() | It reverses the order of the elements of an array. |
| sort() | It represents the source code of an object. |

## Sorting in Ascending Order

The `sort()` method is used to arrange elements in ascending order.

For strings:

```javascript
var fruits = ["Mango", "Apple", "Banana"];
fruits.sort();
```

For numbers (ascending order):

```javascript
var numbers = [40, 10, 100, 25];
numbers.sort(function(a, b) {
    return a - b;
});
```

---

## Adding and Removing Elements

### Adding Element (push)

```javascript
var arr = [1, 2, 3];
arr.push(4);
```

Now array becomes:  
`[1, 2, 3, 4]`

### Removing Element (pop)

```javascript
arr.pop();
```

Now array becomes:  
`[1, 2, 3]`
