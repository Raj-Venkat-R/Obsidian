# Web Application Security – Two Marks Answers

---

## 1. Define Web Application Security.

Web Application Security refers to the practice of protecting websites and web applications from cyber attacks, unauthorized access, data theft, and damage. It includes using security measures like authentication, encryption, input validation, and secure coding to ensure that user data and system resources are safe.

---

## 2. What is meant by Authentication?

Authentication is the process of verifying the identity of a user. It checks whether the person trying to access a system is really who they claim to be. This is usually done using a username and password, OTP, fingerprint, or other verification methods.

---

## 3. Differentiate between Authentication and Authorization.

Authentication verifies **who the user is**, while Authorization determines **what the user is allowed to do**. Authentication happens first during login, and authorization happens after login to control access to resources.

---

## 4. What is Secure Socket Layer (SSL)?

Secure Socket Layer (SSL) is a security protocol that encrypts the data sent between a web browser and a web server. It ensures that sensitive information like passwords and credit card details cannot be easily intercepted by attackers.

---

## 5. Define Transport Layer Security (TLS).

Transport Layer Security (TLS) is an improved and more secure version of SSL. It provides encryption and secure communication between client and server over the internet. TLS ensures confidentiality, integrity, and data protection.

---

## 6. What is Session Management?

Session Management is the process of maintaining a user’s login state while they interact with a web application. After login, a session ID is created to remember the user until they log out or the session expires.

---

## 7. What is Input Validation?

Input Validation is the process of checking the data entered by users before processing it. It ensures that only valid and safe data is accepted by the application, preventing malicious inputs.

---

## 8. Define Security Testing.

Security Testing is the process of testing a software application to identify vulnerabilities and security weaknesses. It ensures that the system is protected against attacks like SQL injection, XSS, and unauthorized access.

---

## 9. What is Security Incident Response Planning?

Security Incident Response Planning is the preparation of a structured plan to handle security breaches or cyber attacks. It includes identifying, managing, and recovering from security incidents quickly to reduce damage.

---

## 10. Expand OWASP and state its role.

OWASP stands for **Open Web Application Security Project**. It is a non-profit organization that provides guidelines, tools, and best practices to improve web application security. It helps developers understand and prevent common security risks.

---

## 11. What is Software Security?

Software Security refers to the practice of designing and developing software in a way that protects it from attacks, vulnerabilities, and unauthorized access. It ensures that the application works safely and securely.

---

## 12. Define Web Application Threat.

A Web Application Threat is any potential danger that can exploit weaknesses in a web application. Examples include hacking, malware injection, data theft, and denial-of-service attacks.

---

## 13. What is Authorization in web security?

Authorization in web security is the process of granting or denying access to resources based on user permissions. It ensures that users can only access data or perform actions that they are allowed to.

---

## 14. State the purpose of HTTPS.

The purpose of HTTPS is to provide secure communication between a web browser and a web server. It encrypts data using SSL/TLS to prevent attackers from intercepting sensitive information.

---

## 15. What is a Digital Certificate?

A Digital Certificate is an electronic document issued by a trusted authority that verifies the identity of a website or organization. It is used in HTTPS to establish secure communication.

---

## 16. What is Session Fixation?

Session Fixation is a type of attack where an attacker forces a user to use a known session ID. After the user logs in, the attacker can use the same session ID to access the account.

---

## 17. What is Server-side Input Validation?

Server-side Input Validation is the process of validating user input on the server before processing it. It ensures security because client-side validation can be bypassed by attackers.

---

## 18. What is meant by Secure Deployment?

Secure Deployment means releasing and configuring software in a secure environment. It includes setting proper permissions, using HTTPS, securing servers, and removing unnecessary services.

---

## 19. Define Vulnerability.

A Vulnerability is a weakness or flaw in a system, software, or network that can be exploited by attackers to gain unauthorized access or cause damage.

---

## 20. What is OWASP Top 10?

OWASP Top 10 is a list published by OWASP that highlights the ten most critical security risks in web applications. It helps developers understand common threats and take preventive measures.
