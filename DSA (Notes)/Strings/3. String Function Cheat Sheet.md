# Java String – Essential Methods Cheat Sheet

## 1. Basic Information

| Method | Description | Example |
|--------|------------|---------|
| `length()` | Returns number of characters | `s.length()` |
| `isEmpty()` | Checks if string length is 0 | `s.isEmpty()` |
| `isBlank()` | Checks if string is empty or whitespace (Java 11+) | `s.isBlank()` |

---

## 2. Character Access

| Method | Description | Example |
|--------|------------|---------|
| `charAt(int index)` | Returns character at index | `s.charAt(2)` |
| `toCharArray()` | Converts string to char array | `s.toCharArray()` |

---

## 3. Comparison

| Method                        | Description                       | Example                    |
| ----------------------------- | --------------------------------- | -------------------------- |
| `equals(String)`              | Compares content                  | `a.equals(b)`              |
| `equalsIgnoreCase(String)`    | Ignores case                      | `a.equalsIgnoreCase(b)`    |
| `compareTo(String)`           | Lexicographic comparison          | `a.compareTo(b)`           |
| `compareToIgnoreCase(String)` | Case-insensitive compare          | `a.compareToIgnoreCase(b)` |
| `==`                          | Compares references (not content) | `a == b`                   |

---

## 4. Searching

| Method | Description | Example |
|--------|------------|---------|
| `contains(CharSequence)` | Checks substring | `s.contains("ab")` |
| `indexOf(char)` | First occurrence | `s.indexOf('a')` |
| `indexOf(String)` | First substring occurrence | `s.indexOf("ab")` |
| `lastIndexOf(char)` | Last occurrence | `s.lastIndexOf('a')` |
| `startsWith(String)` | Checks prefix | `s.startsWith("ab")` |
| `endsWith(String)` | Checks suffix | `s.endsWith("yz")` |

---

## 5. Substring & Slicing

| Method | Description | Example |
|--------|------------|---------|
| `substring(int begin)` | From index to end | `s.substring(2)` |
| `substring(int begin, int end)` | Begin inclusive, end exclusive | `s.substring(1, 4)` |

Important:  
`begin` inclusive, `end` exclusive.

---

## 6. Modification (Creates New String)

| Method | Description | Example |
|--------|------------|---------|
| `concat(String)` | Concatenates | `s.concat("x")` |
| `replace(char, char)` | Replace characters | `s.replace('a','b')` |
| `replace(String, String)` | Replace substring | `s.replace("ab","xy")` |
| `toLowerCase()` | Convert to lowercase | `s.toLowerCase()` |
| `toUpperCase()` | Convert to uppercase | `s.toUpperCase()` |
| `trim()` | Remove leading/trailing spaces | `s.trim()` |
| `strip()` | Unicode-aware trim (Java 11+) | `s.strip()` |

All these return a **new String** (immutability).

---

## 7. Splitting & Joining

| Method | Description | Example |
|--------|------------|---------|
| `split(String regex)` | Splits string | `s.split(" ")` |
| `String.join()` | Joins strings | `String.join("-", arr)` |

Example:
```java
String[] parts = s.split(" ");
String result = String.join("-", parts);
```

---

## 8. Conversion

| Method | Description | Example |
|--------|------------|---------|
| `valueOf(int)` | Converts number to string | `String.valueOf(10)` |
| `Integer.parseInt(String)` | String to int | `Integer.parseInt("123")` |
| `toString()` | Object to string | `obj.toString()` |

---

## 9. Useful Patterns for LeetCode

### Traverse characters
```java
for (int i = 0; i < s.length(); i++) {
    char c = s.charAt(i);
}
```

### Convert to char array
```java
char[] arr = s.toCharArray();
```

### Build string efficiently
```java
StringBuilder sb = new StringBuilder();
sb.append("abc");
String result = sb.toString();
```

---

## Key Reminders

- String is immutable.
- All modification methods create new objects.
- Use `.equals()` for content comparison.
- Use `StringBuilder` for heavy concatenation.
- `substring(begin, end)` → end is exclusive.
