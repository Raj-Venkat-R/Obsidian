# Java Arrays – Functions Cheat Sheet

Note: Arrays themselves do not have methods.  
Utility functions are provided by the `java.util.Arrays` class.

Import:
```java
import java.util.Arrays;
```

---

## 1. Basic Information

### Length
```java
arr.length
```
Returns number of elements.

---

## 2. Printing Arrays

### Convert to String
```java
Arrays.toString(arr);
```

Example:
```java
int[] arr = {1, 2, 3};
System.out.println(Arrays.toString(arr));
```

For 2D arrays:
```java
Arrays.deepToString(matrix);
```

---

## 3. Sorting

### Sort Entire Array
```java
Arrays.sort(arr);
```

### Sort Range
```java
Arrays.sort(arr, fromIndex, toIndex);
```
Note: `toIndex` is exclusive.

---

## 4. Binary Search (Array Must Be Sorted)

```java
Arrays.binarySearch(arr, key);
```

If found:
- Returns index

If not found:
- Returns negative value

---

## 5. Filling Arrays

### Fill Entire Array
```java
Arrays.fill(arr, value);
```

### Fill Range
```java
Arrays.fill(arr, fromIndex, toIndex, value);
```

---

## 6. Copying Arrays

### Copy Entire Array
```java
int[] copy = Arrays.copyOf(arr, newLength);
```

### Copy Range
```java
int[] copy = Arrays.copyOfRange(arr, from, to);
```

`to` is exclusive.

---

## 7. Comparing Arrays

### Check Equality (Content)
```java
Arrays.equals(arr1, arr2);
```

For 2D arrays:
```java
Arrays.deepEquals(matrix1, matrix2);
```

Note:
Do NOT use `==` for content comparison.

---

## 8. Converting Array to List

```java
List<Integer> list = Arrays.asList(1, 2, 3);
```

Important:
- Works with object types only (Integer, not int)
- Fixed-size list (cannot add/remove)

---

## 9. Converting List to Array

```java
Integer[] arr = list.toArray(new Integer[0]);
```

---

## 10. Manual Useful Patterns

### Reverse Array
```java
for (int i = 0; i < arr.length / 2; i++) {
    int temp = arr[i];
    arr[i] = arr[arr.length - 1 - i];
    arr[arr.length - 1 - i] = temp;
}
```

---

### Find Max
```java
int max = arr[0];
for (int i = 1; i < arr.length; i++) {
    if (arr[i] > max) {
        max = arr[i];
    }
}
```

---

### Prefix Sum
```java
int[] prefix = new int[arr.length];
prefix[0] = arr[0];

for (int i = 1; i < arr.length; i++) {
    prefix[i] = prefix[i - 1] + arr[i];
}
```

---

## 11. Time Complexity Notes

| Operation | Complexity |
|------------|------------|
| Access | O(1) |
| Update | O(1) |
| Traversal | O(n) |
| Sort | O(n log n) |
| Binary Search | O(log n) |
| Copy | O(n) |

---

## Key Reminders

- Arrays are fixed size.
- Use `Arrays` class for utility operations.
- `==` compares references, not contents.
- Sorting is required before binary search.
- Range methods use exclusive end index.
