# Circular Queue – Concept

## Problem with Normal Queue (Array Implementation)

In a normal array-based queue:

```text
[ _ _ _ _ _ ]
  ↑       ↑
front     rear
```

After performing operations:

- Enqueue: 1, 2, 3, 4, 5  
- Dequeue: 1, 2  

Array becomes:

```text
[ _ _ 3 4 5 ]
      ↑   ↑
    front rear
```

---

## Issue

- Empty space exists at the beginning
- But `rear` is at the last index
- New elements cannot be inserted

This leads to:

> **False overflow** (queue appears full but is not)

---

# Solution: Circular Queue

A **Circular Queue** treats the array as circular instead of linear.

> After the last index, it wraps back to index 0

---

## Core Idea

Reuse empty spaces by wrapping around.

---

## Key Formulas

### Move Rear

```java
rear = (rear + 1) % size;
```

### Move Front

```java
front = (front + 1) % size;
```

---

## Why Modulo Works

Example (size = 5):

```text
rear = 4
(rear + 1) % 5 = 0
```

This brings the pointer back to the beginning.

---

## Conditions (Very Important)

### Queue is EMPTY when:

```java
front == -1
```

---

### Queue is FULL when:

```java
(front == (rear + 1) % size)
```

Meaning:

- Rear is just behind front (circularly)
- No space left to insert

---

## Operations

### Enqueue (Insert)

Steps:

1. Check if queue is full  
2. If empty → set `front = 0`  
3. Update rear:
   ```java
   rear = (rear + 1) % size;
   ```
4. Insert element at `rear`

---

### Dequeue (Remove)

Steps:

1. Check if queue is empty  
2. Remove element at `front`  
3. If only one element:
   ```java
   front = rear = -1;
   ```
4. Else:
   ```java
   front = (front + 1) % size;
   ```

---

## Example Flow

Initial:

```text
[ _ _ _ _ _ ]
front = -1, rear = -1
```

After inserting 1, 2, 3:

```text
[1 2 3 _ _]
front = 0, rear = 2
```

After removing 1:

```text
[_ 2 3 _ _]
front = 1, rear = 2
```

After inserting 4, 5:

```text
[_ 2 3 4 5]
front = 1, rear = 4
```

After inserting next element (wrap-around):

```text
[6 2 3 4 5]
front = 1, rear = 0
```

---

## Time Complexity

| Operation | Complexity |
|----------|-----------|
| Enqueue | O(1) |
| Dequeue | O(1) |
| Peek | O(1) |

---

## Key Differences

| Feature | Normal Queue | Circular Queue |
|--------|-------------|---------------|
| Space Usage | Inefficient | Efficient |
| Overflow | Possible early | Only when truly full |
| Memory Reuse | No | Yes |

---

## Core Mental Model

Circular queue avoids wasted space by treating the array as a loop.

Pointers move in a circular manner using modulo arithmetic.

---

## Key Takeaways

- Circular queue solves **false overflow**
- Uses modulo to wrap around
- Efficiently reuses freed space
- Full condition is **front == (rear + 1) % size**
