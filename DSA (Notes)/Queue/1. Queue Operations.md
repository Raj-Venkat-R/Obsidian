# Queue – Basics

## Definition

A **Queue** is a linear data structure that follows:

**FIFO (First In, First Out)**

The element inserted first is removed first.

---

## Structure

Queue has two ends:

- **Front** → where elements are removed  
- **Rear** → where elements are inserted  

```
Front → [1, 2, 3, 4] ← Rear
```

---

## Core Operations

### Enqueue (Insert at Rear)

```java
queue.add(10);
queue.offer(10);
```

---

### Dequeue (Remove from Front)

```java
queue.remove();
queue.poll();
```

---

### Peek (Access Front Element)

```java
queue.peek();
queue.element();
```

---

### Utility Methods

```java
queue.isEmpty();
queue.size();
```

---

## Important Method Differences

### add() vs offer()

- `add()` → throws exception if queue is full  
- `offer()` → returns false if insertion fails  

Preferred: **offer()**

---

### remove() vs poll()

- `remove()` → throws exception if empty  
- `poll()` → returns null if empty  

Preferred: **poll()**

---

### peek() vs element()

- `peek()` → returns null if empty  
- `element()` → throws exception  

Preferred: **peek()**

---

## Summary Table

| Operation | Safe Method | Risky Method |
|----------|-------------|-------------|
| Insert | offer() | add() |
| Remove | poll() | remove() |
| Access | peek() | element() |

---

## Time Complexity

| Operation | Complexity |
|----------|-----------|
| Enqueue | O(1) |
| Dequeue | O(1) |
| Peek | O(1) |

---

## Java Implementation

Queue is an interface.

```java
Queue<Integer> q1 = new LinkedList<>();
Queue<Integer> q2 = new ArrayDeque<>();
```

Preferred: **ArrayDeque**

Reason:
- Faster
- No extra overhead

# Types of Queue

## 1. Simple Queue

- Follows FIFO
- Insert at rear, remove from front

Used in:
- BFS
- Scheduling
- Task processing

---

## 2. Circular Queue

### Problem in Normal Queue

Unused space cannot be reused after dequeue.

### Solution

Treat array as circular.

```java
rear = (rear + 1) % size;
front = (front + 1) % size;
```

### Key Idea

Efficient use of memory by reusing space.

---

## 3. Deque (Double Ended Queue)

Allows insertion and deletion from both ends.

```java
Deque<Integer> dq = new ArrayDeque<>();

dq.addFirst(10);
dq.addLast(20);

dq.removeFirst();
dq.removeLast();
```

Used in:
- Sliding window problems
- Monotonic queue

---

## 4. Priority Queue

Does not follow FIFO.

Elements are removed based on **priority**.

Default in Java:
- **Min Heap**

```java
PriorityQueue<Integer> pq = new PriorityQueue<>();
```

Example:

```java
pq.add(5);
pq.add(1);
pq.add(3);

pq.poll();  // returns 1
```

Used in:
- Dijkstra algorithm
- Top K problems
- Scheduling

---

## Core Differences

| Type | Order | Use Case |
|------|------|---------|
| Queue | FIFO | BFS |
| Deque | Both ends | Sliding window |
| Priority Queue | Priority-based | Greedy / Graph |

---

## Core Mental Model

Queue processes elements in **arrival order**.

Insertion happens at rear.  
Removal happens at front.
