# BFS – Breadth First Search

## Definition

BFS is a graph traversal technique that explores nodes **level by level**.

It visits all nodes at the current distance before moving to the next level.

---

## Core Idea

BFS explores:

- First → immediate neighbors  
- Then → neighbors of neighbors  

This ensures traversal in **increasing distance order**.

---

## Why Queue is Used

Queue follows **FIFO (First In, First Out)**.

- Nodes are processed in the order they are discovered  
- Ensures correct level-by-level traversal  

---

## BFS Flow

1. Start from source node  
2. Add it to queue  
3. Mark it as visited  
4. While queue is not empty:
   - Remove front node  
   - Visit it  
   - Add all unvisited neighbors to queue  

---

## Important Rule

**Mark node as visited when adding to queue (enqueue)**

Reason:
- Prevents adding the same node multiple times  
- Avoids infinite loops in cyclic graphs  

---

## Why Visited Array is Required

Without visited tracking:

- Same node may be added multiple times  
- Graph with cycles → infinite loop  
- Incorrect traversal  

---

## BFS Template (Core Pattern)

```java
Queue<Integer> q = new ArrayDeque<>();
boolean[] visited = new boolean[n];

q.add(start);
visited[start] = true;

while (!q.isEmpty()) {
    int node = q.poll();

    for (int neighbor : adj[node]) {
        if (!visited[neighbor]) {
            visited[neighbor] = true;
            q.add(neighbor);
        }
    }
}
```

---

## Key Property

BFS guarantees **shortest path in an unweighted graph**.

Reason:
- Nodes are explored level by level  
- First time reaching a node = minimum distance  

---

## Graph Representation

### Adjacency List

```text
0 → [1, 2]
1 → [0, 3]
2 → [0]
3 → [1]
```

Preferred for most problems.

---

## BFS in Grid (Very Important)

Used in matrix problems.

### Movement Directions

```java
int[][] dir = {
    {1, 0}, {-1, 0}, {0, 1}, {0, -1}
};
```

---

## Grid BFS Template

```java
Queue<int[]> q = new ArrayDeque<>();
boolean[][] visited = new boolean[m][n];

q.add(new int[]{startRow, startCol});
visited[startRow][startCol] = true;

while (!q.isEmpty()) {
    int[] cell = q.poll();
    int r = cell[0];
    int c = cell[1];

    for (int[] d : dir) {
        int nr = r + d[0];
        int nc = c + d[1];

        if (nr >= 0 && nc >= 0 && nr < m && nc < n 
            && !visited[nr][nc]) {

            visited[nr][nc] = true;
            q.add(new int[]{nr, nc});
        }
    }
}
```

---

## Time Complexity

O(V + E)

- V = number of vertices  
- E = number of edges  

---

## Space Complexity

O(V)

- For queue and visited array  

---

## Key Takeaways

- BFS uses a **queue**  
- Traverses **level by level**  
- Always use a **visited array**  
- Mark visited **during enqueue**  
- Guarantees shortest path in **unweighted graphs**  
- Grid BFS is a common variation
