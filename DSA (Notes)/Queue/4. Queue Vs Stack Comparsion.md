# Stack vs Queue – Comparison

## Definition

### Stack

A **Stack** is a linear data structure that follows:

**LIFO (Last In, First Out)**

The last element inserted is removed first.

---

### Queue

A **Queue** is a linear data structure that follows:

**FIFO (First In, First Out)**

The first element inserted is removed first.

---

## Structure

### Stack

- Uses a single end called **Top**
- All operations happen at the top

```
Top → [3]
       [2]
       [1]
```

---

### Queue

- Uses two ends:
  - **Front** → removal
  - **Rear** → insertion

```
Front → [1, 2, 3] ← Rear
```

---

## Operations

### Stack

```java
stack.push(x);   // insert
stack.pop();     // remove
stack.peek();    // access top
```

---

### Queue

```java
queue.offer(x);  // insert
queue.poll();    // remove
queue.peek();    // access front
```

---

## Order of Processing

| Feature | Stack | Queue |
|--------|------|------|
| Order | LIFO | FIFO |
| Processing | Depth-first | Breadth-first |

---

## Use Cases

### Stack

Used in:

- Recursion (call stack)
- Backtracking
- Expression evaluation
- Undo/redo operations
- Monotonic stack problems

---

### Queue

Used in:

- BFS (graph traversal)
- Level order traversal (trees)
- Scheduling systems
- Buffering and streaming

---

## Algorithm Usage

| Algorithm | Data Structure |
|----------|--------------|
| DFS | Stack |
| BFS | Queue |

---

## Key Differences

| Feature | Stack | Queue |
|--------|------|------|
| Insertion | Top | Rear |
| Deletion | Top | Front |
| Ends Used | One end | Two ends |
| Behavior | Last-in-first-out | First-in-first-out |

---

## Core Mental Model

- Stack processes elements in **reverse order of insertion**
- Queue processes elements in **same order of insertion**

---

## Important Insight

- Stack is used when **recent element matters**
- Queue is used when **order of arrival matters**
